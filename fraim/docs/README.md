## FRAIM In One Minute

FRAIM's primary execution unit is a **job**.

- **Jobs** define the phased path for a task.
- **Phases** are the gates inside a job.
- **Skills** provide reusable execution patterns that jobs compose.
- **Rules** define always-on constraints and quality standards.
- **Templates** define reusable deliverable formats and can also be personalized locally.
- **The AI Mentor** helps the agent stay in the correct phase and asks for evidence before advancing.

If you still see old references to "workflows" in older discussions or historical docs, read them as the legacy term for what FRAIM now models primarily as jobs.

## Best First Prompts

After FRAIM is connected in your IDE:

- `Onboard this project`
- `Personalize my employee`
- `List FRAIM jobs`
- `Run the feature-implementation job for issue #123`
- `Run the follow-your-mentor manager job if the agent drifted`
- `Run the analyze-why-you-messed-up manager job after a significant miss`
- `Which FRAIM job should I use for this request?`

## Visualize Your FRAIM

Use the FRAIM Brain to see the full job and skill topology:

- `https://fraim.wellnessatwork.me/fraim-brain`

What it shows:

- all available FRAIM jobs on the perimeter
- the skills those jobs activate inside the brain
- a personalized "Your Brain" overlay when you provide your FRAIM API key

Use analytics for personalized usage trends:

- `https://fraim.wellnessatwork.me/analytics`

What it shows:

- your job, skill, rule, and mentoring activity over time
- top components you are using most
- success rate and duration trends
