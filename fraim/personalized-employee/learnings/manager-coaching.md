### Proposed new entry

#### [P-MED] State the deliverable format at kickoff when a specific one is needed

**Recommendation**: When the output needs to be in a particular format (Word, PDF, slides), say so at the start — it saves a rework round.

**Why FRAIM is proposing this**: On the board-alternative task the manager asked for a Word file only after the markdown deliverable was complete. The work was right; the extra round was purely a format conversion that up-front direction would have avoided. This is a low-cost manager habit that improves throughput.

**Example**: The cost-down analysis was approved on its merits, but a full round was spent re-rendering the finished markdown to Word — avoidable had "deliver as a Word file" been stated in the initial ask.

**If approved, future behavior changes**: The manager notes the desired final format up front when it matters; the agent, for its part, may ask "any particular format?" when a deliverable's destination is unclear.

**Scope if approved**: Save for all projects on this machine.
