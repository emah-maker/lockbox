# FRAIM Job: what-should-i-review

## Intent
Help a manager efficiently process their PR queue by analyzing each PR against its linked issue requirements, detecting risks with confidence-scored action items, and prioritizing across the queue so the manager knows exactly where to focus their review time.

## Outcome
- **Queue Triage**: All open PRs classified as Quick Approve / Focused Review / Deep Review.
- **Per-PR Briefing**: Summary, ranked action items (file/line, risk, confidence), spec coverage.
- **Reviewer Time Savings**: Manager knows which PRs to skim, which need focused attention, and which require deep review.
- **Artifact**: `docs/evidence/{issue_number}-pr-review-triage.md` with the complete briefing.

## Steps
1. Phase 1: `queue-intake`
2. Phase 2: `spec-and-context-loading`
3. Phase 3: `per-pr-review`
4. Phase 4: `queue-triage`
5. Phase 5: `briefing-and-submission`
6. Phase 6: `retrospective`
