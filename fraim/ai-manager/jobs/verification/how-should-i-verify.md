# FRAIM Job: how-should-i-verify

## Intent
Help the manager decide which verification method best fits the agent's work, then give the user exact steps to verify the work correctly.

## Outcome
- The work claim is classified clearly enough to choose the right proof method.
- One of a small set of standard verification methods is selected with explicit rationale.
- The user receives an exact verification brief and, when evidence already exists, a judgment on whether that evidence is strong enough.

## Steps
1. Phase 1: `understand-work-claim`
2. Phase 2: `choose-verification-method`
3. Phase 3: `write-user-verification-brief`
4. Phase 4: `assess-evidence`
5. Phase 5: `submit`
