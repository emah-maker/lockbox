# FRAIM Job: manager-agreements

## Intent
Agree once on how you like to work with your team — your working style, how you give and want feedback, and how you want deliverables presented — so every AI employee adapts to you instead of guessing on each interaction.

## Outcome
- `manager_context.md` captures your working style, feedback approach, and presentation preference.
- `manager_rules.md` captures standing manager-level behavior rules.
- Both artifacts live machine-local by default at `~/.fraim/personalized-employee/`. If the manager explicitly chooses a shared backend, they live in the configured personal manager backend so they can follow the FRAIM account across machines.
- The manager has reviewed both artifacts through the normal submit/feedback flow and knows these manager-level agreements are inherited by every project's employees.

## Steps
1. Phase 0: `sync`
2. Phase 1: `scope`
3. Phase 2: `synthesize`
4. Phase 3: `validate`
5. Phase 4: `submit`
6. Phase 5: `address-feedback`
7. Phase 6: `retrospective`
