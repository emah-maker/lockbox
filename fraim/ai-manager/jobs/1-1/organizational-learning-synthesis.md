# FRAIM Job: organizational-learning-synthesis

## Intent
Synthesize cross-user patterns from all users' L1 learning files into proposed `org-*.md` L2 files. Identifies patterns that multiple users hit independently, validates them against existing L2 entries, and flags demotion candidates. Produces pending sections for scrum master review — does not promote entries autonomously.

## Outcome
- **Pending sections written** to affected `org-*.md` files (`org-mistake-patterns.md`, `org-preferences.md`, `org-manager-coaching.md`, `org-validated-patterns.md`), and to domain-scoped `org-<domain>-<filetype>.md` files when a graduating pattern is specific to one job-domain.
- **Demotion candidates flagged**: existing L2 entries where only one user's signal remains active.
- **No other writes**: L1 files, `project_rules.md`, and confirmed L2 body content are untouched until the scrum master approves.

## Steps
1. Phase 1: `gather-l1`
2. Phase 2: `analyze`
3. Phase 3: `write-proposals`
4. Phase 4: `review`
5. Phase 5: `apply`
6. Phase 6: `submit`
