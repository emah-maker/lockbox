# FRAIM Job: sleep-on-learnings

## Intent
Consolidate the user's unprocessed L0 learning signals (coaching moments + retrospectives) into proposed L1 updates, walk the user through those proposals for approval or edits, then apply the approved changes so the learnings stick. The sleep metaphor is deliberate: synthesize first, review what should persist, and only then commit the durable memory.

## Outcome
- **Fresh pending sections written**: each affected L1 file (preferences, manager-coaching, mistake-patterns, validated-patterns) has its existing `## Pending Review` section overwritten with a freshly synthesized one covering **all** currently unprocessed signals in `raw/` plus all unsynthesized retrospectives. (L2 candidacy is NOT decided here - L2 is cross-user org-level synthesis, owned by `organizational-learning-synthesis`.)
- **User-reviewed promotions applied**: approved proposals are promoted into the L1 body, approved updates replace the old entry, and conflict resolutions are recorded inline.
- **Source signals cleaned up**: raw L0 files corresponding to approved proposals are archived, retrospectives whose content was used in an approved proposal get `synthesized: YYYY-MM-DD` in frontmatter, and processed artifacts are evaluated against `artifact_retention_period`.
- **Rejected proposals suppressed**: rejected proposals are recorded so future runs do not keep re-proposing the same rejected pattern.

## Steps
1. Phase 1: `gather-signals`
2. Phase 2: `analyze`
3. Phase 3: `write-proposals`
4. Phase 4: `review-pending`
5. Phase 5: `apply`
6. Phase 6: `submit`
7. Phase 7: `address-feedback`
8. Phase 8: `retrospective`
