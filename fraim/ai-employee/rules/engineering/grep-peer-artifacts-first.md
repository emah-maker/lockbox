# FRAIM Rule: grep-peer-artifacts-first

## Intent
Before writing any new path, file, pattern, UI design, architecture layer, API field value, shared-file edit, or auth route, grep the repo for peer artifacts that already solve the same concern. Let those findings constrain the new work. Inventing independently when a convention already exists is a P-CRITICAL recurring failure mode.
