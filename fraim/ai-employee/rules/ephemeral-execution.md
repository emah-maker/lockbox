# FRAIM Rule: ephemeral-execution

## Intent
To enable reliable, consistent script execution across different environments by leveraging pre-synchronized local scripts rather than dynamic fetching, ensuring agents can execute FRAIM workflows without network dependencies or synchronization delays.

FRAIM scripts are pre-synchronized to the user's local directory and executed directly from there.
