# FRAIM Skill: codebase-architecture-analysis

## Skill Input
- `rootPath`: Absolute path to the target repository root to evaluate
- `focusAreas`: Optional specific sub-system directories to focus the analysis on
- `analysisType`: Type of analysis needed - "discovery" (understand existing), "synthesis" (design new), or "comprehensive" (both)

## Skill Output
- `projectStructure`: Overview of the directory structure and organization
- `techStackIndicators`: Identified technologies, frameworks, runtimes, and dependencies
- `entryPoints`: Main entry points and application startup flows
- `architecturalPatterns`: Inferred architectural patterns (MVC, microservices, event-driven, etc.)
- `componentLayers`: System layers (Presentation, Logic, Data, APIs) and their relationships
- `dataFlows`: Key data integration flows and component interactions
- `architecturalInsights`: Synthesized recommendations and architectural decisions
