# FRAIM Skill: sf-streaming

## Skill Input
- `conn`: A jsforce Connection with a valid `accessToken` (from `sf-auth` skill).
- `channel`: The CometD channel to subscribe to. Common channels:
  - `/event/CaseChangeEvent` — real-time Case creates/updates
  - `/event/OpportunityChangeEvent` — real-time Opportunity creates/updates
  - `/event/AccountChangeEvent` — real-time Account creates/updates
  - `/event/AIPredictionEvent` — Einstein AI prediction output events
- `onEvent(event)`: Callback function invoked for each received event.
- `timeout`: Maximum time to listen in milliseconds (default: 30,000 for single-event use; omit for continuous subscription).
- `replayId`: Optional CometD replay ID for replaying missed events (default: -1 = all new events).

## Skill Output
- Events delivered to the `onEvent` callback as they arrive.
- A `stop()` function to unsubscribe and close the CometD connection.
- A summary of events received: count, first event timestamp, last event timestamp, any re-subscription events.
