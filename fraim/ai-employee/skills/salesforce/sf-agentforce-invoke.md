# FRAIM Skill: sf-agentforce-invoke

## Skill Input
- `accessToken`: The Salesforce OAuth Bearer token (from `sf-auth` skill). Used as the Authorization header for `api.salesforce.com`.
- `copilotId`: The Salesforce record ID of the Agentforce agent (key prefix `0Xx`, e.g. `0Xxfj000001vWXFCA2`). Found in the Agentforce Builder URL: `.../builder?copilotId={id}`.
- `message`: The user message text to send to the agent.
- `externalSessionKey`: Optional stable session identifier for the calling system (e.g. `fraim-case-{caseId}`). Used for idempotency. Defaults to a generated UUID.
- `variables`: Optional array of Agentforce context variables `[{ name, type, value }]`.

## Skill Output
- `sessionId`: UUID of the created Agentforce session.
- `agentResponse`: The agent's final text response after subagent selection and action execution.
- `planSummary`: Structured plan data including subagent selected, reasoning duration, actions taken, output evaluation result (GROUNDED / NOT_GROUNDED).
- `sessionUrl`: The session URL for further messages in the same conversation thread.
