# FRAIM Skill: sf-auth

## Skill Input
- `SF_INSTANCE_URL`: The Salesforce org instance URL (e.g. `https://orgname.my.salesforce.com`). Required.
- `SF_CONSUMER_KEY`: The Connected App consumer key. Read from environment or vault. Required.
- `SF_PRIVATE_KEY_PATH` or `SF_PRIVATE_KEY`: Path to PEM file or raw PEM string for JWT signing. Required.
- `SF_USERNAME`: The Salesforce API user username (e.g. `api-user@org.com`). Required.
- `SF_API_VERSION`: API version string (default: `66.0`).

## Skill Output
- A jsforce `Connection` object with `accessToken`, `instanceUrl`, and `version` set, ready for SOQL queries, CRUD, Metadata API, Tooling API, and Bulk API calls.
- The raw `accessToken` string for use in direct HTTPS calls to `api.salesforce.com` (Agentforce endpoint).
