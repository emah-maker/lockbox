# FRAIM Skill: sf-crud

## Skill Input
- `conn`: A jsforce Connection with a valid `accessToken` (from `sf-auth` skill).
- `operation`: One of `create`, `update`, `upsert`, `delete`, `bulkQuery`, `bulkUpsert`.
- `objectType`: Salesforce sObject API name.
- `records`: Array of record objects (for create/update/upsert) or record IDs (for delete). Maximum 25 records for composite batch; use Bulk API 2.0 for larger sets.
- `externalIdField`: Required for upsert operations.
- `batchMode`: If true, use composite batch API (up to 25 operations in one HTTP call).

## Skill Output
- For single/batch operations: array of `{ id, success, errors }` results.
- For bulk operations: `{ jobId, state, recordsProcessed, recordsFailed }`.
