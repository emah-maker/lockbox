# FRAIM Skill: issue-documentation

## Skill Input
- `issueTitle`: Clear, descriptive title.
- `category`: Critical, High, Medium, Low.
- `type`: Functionality, UI/UX, Data, Performance, Security.
- `pageFeature`: Where the issue occurs.
- `useCase`: Related use case.

- `stepsToReproduce`: Steps to reproduce the issue.
- `expectedBehavior`: What should happen.
