# FRAIM Skill: rich-review-artifact-contract

## Skill Input
- `artifactPath`: Where the review artifact or bundle README will be written.
- `subjectType`: Short category for the thing under review (for example `repository`, `feature-review`, `delivery-motion`, `brand`, `strategy-artifact-set`, `compliance-bundle`).
- `subjectLabel`: Human-readable label for the reviewed subject.
- `reviewRef`: Stable shallow reference such as issue number, PR number, branch/ref label, date window, or user-provided slug.
- `scopeSummary`: One or two sentences describing what was reviewed.
- `repoIdentifier` (optional): Stable repository identifier such as the repository remote URL when the review is tied to a repo.
- `branchRef` (optional): Branch or PR head label when branch context materially affects the review.
- `sourceInventory`: Up to 5 project-relative paths or redacted external source labels.
- `dimensionFindings`: The scored dimensions, rationales, and coaching notes produced by the calling workflow.

## Skill Output
- A durable review artifact with consistent machine-readable frontmatter and a coaching-rich body.
- A minimal MCP evidence shape suitable for the final `seekMentoring` call.
