# FRAIM Skill: outreach-metrics-pull

## Skill Input
- The `integrations.recruiting` block from `fraim/config.json`. Shape:
  ```json
  {
    "leadgen": { "provider": "gem|outreach|none", "pipeline_source": "api|browser|csv|manual" }
  }
  ```
- `reqIds[]` (optional): List of req/job IDs to scope the pull. Omit for all active reqs.
- `reportingWindow`: `{ days: number, label: string }` — e.g. `{ days: 14, label: "last 14 days" }`.
- `trendWindow` (optional): `{ days: number, label: string }` — prior comparable window for trend comparison (e.g. `{ days: 14, label: "prior 14 days" }`). Omit to skip trend calculation.

## Skill Output
- `reqMetrics[]`: One entry per req:
  ```
  {
    reqId, reqTitle, sequenceIds[], sequenceNames[], sends, bounces, opens, replies,
    positiveReplies, deliveredSends, openRate, replyRate, positiveReplyRate, bounceRate,
    trend: { sends, replies, positiveReplies, bounces } | null,
    flags: { lowPassThrough, stalled, bounceRisk, noCoverage, ambiguousMapping },
    dataNote: string | null
  }
  ```
  Rate fields are `"n/a"` when the denominator is zero (never a division result).
- `sourceLabels`: `{ outreach: string, extractionMode: string, reportingWindow: string }`.
- `warnings[]`: Credential issues, mapping ambiguities, partial data, browser fragility.
