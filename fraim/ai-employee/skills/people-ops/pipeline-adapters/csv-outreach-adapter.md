# FRAIM Skill: csv-outreach-adapter

## Skill Input
- `csvPath`: Absolute or relative path to the exported outreach stats CSV. Confirm with the user if not provided.
- `reportingWindow`: `{ days: number, label: string }` — used to filter rows by date if the CSV includes a date column.

## Skill Output
- `sequenceMetrics[]`: One entry per sequence row in the CSV:
  ```
  {
    sequenceId, sequenceName, reqId, reqTitle,
    sends, bounces, opens, replies, positiveReplies,
    trendWindow: null
  }
  ```
  `trendWindow` is always `null` in CSV mode — prior-window comparison requires a second CSV export.
- `sourceLabel`: `"CSV export ({provider if known})"`.
- `warnings[]`: Missing columns, unparseable rows, date-filter gaps.
