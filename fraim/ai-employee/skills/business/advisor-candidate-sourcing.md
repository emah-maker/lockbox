# FRAIM Skill: advisor-candidate-sourcing

## Skill Input
- The startup's domain, stage, and the founder's self-identified weak areas (skills, network, credibility gaps).
- Advisor competency categories required (read from applicable program rules if a program defines them; otherwise default to: Startup/operator, Industry/domain, Functional/go-to-market-or-product).
- Target count per category (read from program rules; otherwise default to 3 per category).
- The founder's reachable network (LinkedIn connections, alumni, prior colleagues) when available.

## Skill Output
- A categorized candidate list meeting the per-category target, each entry with: name, title, company, LinkedIn URL, the specific gap they fill, and a one-line "why them".
- A named **Connector** per candidate (a mutual contact who can make a warm introduction), or "cold" if none exists.
- A coverage report: candidates found vs. target per category, and any category still short.
