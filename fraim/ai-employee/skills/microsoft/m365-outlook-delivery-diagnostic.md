# FRAIM Skill: m365-outlook-delivery-diagnostic

## Skill Input
- `senderUpn`: UPN of the sending user (optional; used to scope message trace).
- `recipientUpn`: UPN of the intended recipient (at least one of sender or recipient required).
- `messageSubject`: optional subject substring to narrow trace results.
- `lookbackHours`: optional integer (default 24, max 168 per Exchange message trace limits).

## Skill Output
- `traceResults`: array of message trace records with `messageId`, `senderAddress`, `recipientAddress`, `subject`, `status`, `detail`, `diagnosis`, `lastEventTime`.

- `summary`: plain-text diagnosis string the support agent can paste into the ticket work note.
