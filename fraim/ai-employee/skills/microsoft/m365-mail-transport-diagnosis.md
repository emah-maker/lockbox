# FRAIM Skill: m365-mail-transport-diagnosis

## Skill Input
- `senderUpn` or `senderDomain`: the source address space.
- `recipientUpn` or `recipientDomain`: the destination address space.
- `symptom`: one of `blocked`, `redirected`, `delayed`, `disclaimers-missing`, `general` (default: `general`).

## Skill Output
- `transportRules`: array of rules evaluated with `name`, `priority`, `enabled`, `actions`, `verdict` (`applicable` or `not-applicable`).
- `connectors`: array of outbound/inbound connectors whose scope matches the sender/recipient domain.
- `diagnosis`: plain-text explanation of the most likely cause.
- `requiresExchangeAdmin`: boolean (true when full rule inspection requires Exchange admin permissions not available via Graph).
