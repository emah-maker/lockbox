# FRAIM Skill: utm-and-attribution-setup

## Skill Input
- Marketing channel inventory: all active channels generating traffic (Google Ads, Meta, LinkedIn, email, organic social, direct).
- Analytics platform: Google Analytics 4, Amplitude, Mixpanel, or custom analytics stack.
- Conversion event inventory: the specific actions to track as conversions (form submit, purchase, trial start, demo booked).
- CRM or data warehouse: the system where attribution data will ultimately land for revenue attribution.
- Existing UTM usage (if any): current parameter conventions, any known inconsistencies.

## Skill Output
- **UTM Taxonomy**: Defined values for utm_source, utm_medium, utm_campaign, utm_content, and utm_term per channel. Naming convention enforced.
- **UTM Parameter Matrix**: A lookup table mapping every channel/campaign combination to its UTM string. Used by marketing ops to build links consistently.
- **Conversion Event Specification**: For each conversion event, the trigger condition, the data layer push format, and the analytics platform event name and parameters.
- **Attribution Model Selection**: Recommended attribution model for the business's stage and channel mix, with rationale and known limitations.
- **Deduplication Key**: The mechanism for identifying and removing duplicate conversion events from analytics and CRM.
