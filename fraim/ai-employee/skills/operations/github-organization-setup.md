# FRAIM Skill: github-organization-setup

## Skill Input
- `orgSlug`: Approved GitHub org slug.
- `displayName`: Org display name.
- `description`: Org description (~150 chars).
- `primaryDomain`: Registered company domain for verification.
- `billingPlan`: Approved plan (`Free` | `Team` | `Enterprise`).
- `billingEmail`: Billing contact on the company domain.
- `memberInvites`: Array of `{ username, role, email? }` for founding team.
- `ownerDesignees`: At least two usernames to receive Owner grants.
- `ssoPlan` (optional): If SSO is in scope, the SAML IdP metadata and enforcement-readiness flag.
- `repoPolicyDefaults`: Branch protection values, required review count, linear history, signed-commit policy, auto-delete head branches.

## Skill Output
- `orgUrl`: Live `github.com/{orgSlug}` URL.
- `verificationState`: Domain verification state (`pending` / `verified`).
- `securityBaselineState`: Status of each enforced setting.
- `inviteStatuses`: Per-member invite state.
- `executionLog`: Action log with UI/API payload snapshots.
