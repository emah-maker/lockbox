# FRAIM Skill: gcp-performance-data-collection

## Skill Input
- `targetResources`: List of GCP resource identifiers under investigation (GCE instance names, Cloud Run service names, Cloud SQL instance IDs, GKE workload names).
- `timeRange`: Start and end timestamps (ISO 8601) for the diagnostic window.
- `collectLogs`: Boolean — whether to retrieve Cloud Logging entries in addition to metrics.

## Skill Output
- `metrics`: Cloud Monitoring metric series (CPU, memory, request latency, error rate, network) keyed by resource.
- `traces`: Cloud Trace span summaries for the slowest N traces in the window.
- `profiles`: Cloud Profiler reports for services that have it enabled.
- `logs`: Cloud Logging entries containing performance-relevant patterns (timeouts, OOMs, throttles).
