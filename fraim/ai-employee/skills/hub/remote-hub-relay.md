# FRAIM Skill: remote-hub-relay

## Skill Input
- `hubUrl`: string — base URL of the remote hub (e.g. `https://vm.example.com:3000`)
- `authToken`: string? — value for `X-Hub-Auth` header; omit if hub is unprotected
- `jobId`: string — FRAIM job to run on the remote hub
- `projectPath`: string — project path on the remote machine
- `instructions`: string — manager instructions for the remote job

## Skill Output
- `remoteRunId`: ID of the run created on the remote hub
- `finalStatus`: terminal status of the remote run (`completed` or `failed`)
- `reviewHandoff`: mirrored `reviewHandoff` object from the remote run (if present)
