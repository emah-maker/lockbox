# FRAIM Skill: ui-baseline-validation

## Skill Input
- `uiArtifacts`: One of:
  - `mockHtmlFiles`: Paths to HTML/CSS mock files to open and validate, OR
  - `targetUrls`: URLs/routes to validate in a running app.
- `designStandards`: Optional. A short, phase-provided summary of the applicable design standards (tokens, components, typography, spacing rules). If omitted, validate against a generic baseline (spacing consistency, typography hierarchy, no overlap/clipping, accessible contrast).
- `requiredStates`: Optional list of UI states to validate (loading, empty, error, success, populated).
- `breakpoints`: Optional list of viewport sizes to validate (e.g. `375x812`, `768x1024`, `1280x800`).

## Skill Output
- `baselineUxFindings`: A short list of pass/fail findings with evidence pointers (screenshots/notes) and severity (P0/P1/P2).
