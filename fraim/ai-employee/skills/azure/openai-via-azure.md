# FRAIM Skill: openai-via-azure

## Skill Input
- `subscription_id` - the Azure subscription where Azure OpenAI spend should land and where credits are available.
- `resource_group` - the target resource group for the Azure OpenAI resource and deployment.
- `region` - the Azure region to use. It must support Azure OpenAI and the target model family.
- `model_family` - the OpenAI family the user needs to route (`gpt-4.1`, `gpt-4o`, etc.).
- `deployment_name` - the Azure deployment name that the consuming agent or app will reference.
- `agent` - which agent or app will consume the routed model (`codex`, OpenAI SDK app, custom agent, etc.).

## Skill Output
A working Azure OpenAI setup with:
- an Azure OpenAI resource in the target subscription and region
- a live deployment named `deployment_name`
- endpoint and API key stored outside any repo at `$HOME/.azure-openai/<deployment_name>.json`
- at least one successful direct Azure OpenAI invoke
- runtime configuration facts captured for the consuming agent
