# FRAIM Skill: brand-core-definition

## Skill Input
- `businessContext`: Business, offer, and market context for the target brand.
- `audienceContext`: Intended audience and their relevant tensions.
- `mode`: One of `{new-brand, reposition, rebrand, product-brand, founder-brand, employer-brand, portfolio}`.
- `existingBrandArtifacts` (optional): Current brand materials if the work is not greenfield.

## Skill Output
- `brandCore`: A compact articulation of the brand's WHY, promise, character, role, and center of gravity.
- `supportingNotes`: Key tensions, constraints, and strategic implications.
- `visionStatement` (conditional): Include only if it materially strengthens the brand system for the requested mode.
- `missionStatement` (conditional): Include only if it materially strengthens the brand system for the requested mode.
- `coreValues` (conditional): Include only if they are constraining and distinctive, not generic platitudes.
