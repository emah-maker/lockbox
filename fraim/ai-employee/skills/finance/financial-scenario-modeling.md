# FRAIM Skill: financial-scenario-modeling

## Skill Input
- Base case financial model: a completed three-statement model or operating model with documented assumptions.
- Driver list: the 3–5 variables that most significantly affect the outcome metric (revenue, EBITDA, cash runway).
- Scenario parameters: named scenarios (e.g., Base, Upside, Downside, Stress) with the specific driver values for each.
- Decision context: the business question the scenario analysis is meant to answer (e.g., "When do we need to raise?", "What happens to margin if churn doubles?").

## Skill Output
- **Scenario Summary Table**: Rows = scenarios; columns = key outcome metrics (Revenue, Gross Margin %, EBITDA, Net Cash, Runway). Each cell is a single value — no ranges inside cells.
- **Driver Sensitivity Table**: For the 2–3 most impactful drivers, a sensitivity grid showing how the outcome metric changes as the driver varies ±10%, ±20%, ±30% from base.
- **Scenario Narrative**: One paragraph per scenario describing the business conditions implied by the driver values and the strategic implication of that outcome.
- **Decision Recommendation**: One sentence per scenario on what action the business should take if that scenario materializes.
