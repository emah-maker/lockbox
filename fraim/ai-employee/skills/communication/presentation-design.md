# FRAIM Skill: presentation-design

## Skill Input
- `desiredOutcomes`: A list of 2-3 specific "Landing Zones" or takeaways the presentation must achieve.
- `audienceProfile`: Context on the listeners (e.g., technical, executive, external partners).
- `availableEvidence`: Sources of truth (data points, project telemetry, case studies, SOWs).
- `duration`: (Optional) Target time limit for the presentation.

## Skill Output
- `presentationBlueprint`: A detailed `storyline` including:
  - `openingHook`: A visceral opening connected to the current state/problem.
  - `mainNodes`: Sequential pairs of [Message + Supporting Evidence].
  - `closingResolution`: A thematic wrap-up that resolves the hook and provides a clear Call-to-Action.
- `evidenceMap`: A document tracing every core message back to its harvested source of truth.
