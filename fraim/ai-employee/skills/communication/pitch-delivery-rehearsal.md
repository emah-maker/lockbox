# FRAIM Skill: pitch-delivery-rehearsal

## Skill Input
- The current pitch script and/or deck.
- The target time box (`targetDurationMinutes` — a generic parameter; a program may set specific limits via its rules).
- The setting (hotseat, mentor panel, investor review) and what it is graded on, if anything.

## Skill Output
- A **time-boxed script** tightened to fit the target duration at normal speaking pace (~150 words/minute), with cuts noted.
- A **self-rehearsal checklist**: pacing markers, the one-line per-slide message, likely interrupt points, and a strong open/close.
- A **"what good delivery looks like" rubric** (clarity, one idea, time discipline, confident open/close) the speaker can self-score against.
- A **handoff** to a delivery-coaching tool for recorded practice (see guardrail).
