# FRAIM Skill: author-audio

## Skill Input
- Source markdown or plain-text path (typically a narrative, pitch, or keynote script)
- Optional destination path (default: same directory as input, same basename with `.mp3`)
- Optional rendering options: `format` (mp3/m4a/both), `voice`, `rate`, `pitch`, `start-marker`, `end-marker`, `include-blockquotes`
- Optional author/speaker profile (for voice selection and length estimation defaults)

## Skill Output
- A listenable audio file (mp3 by default, m4a optional) produced from the speakable content of the source document.
- **Only produced when the user has given explicit consent.** A "declined" outcome is a valid and common result — the skill completes cleanly with no audio file in that case.
- Intended use: the author listens to their own work for rehearsal, memorization, proof-listening, or on-the-go consumption.
