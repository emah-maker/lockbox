# FRAIM Skill: support-playbook-evaluation

## Skill Input
- Approved support playbooks from the configured support playbook directory `{{proxy.config.automation.support.playbooks.directory | NO_OP | "playbooks/support"}}`.
- Historical support tickets or curated golden fixtures.
- Expected labels when available from ticket closure codes, historical assignment, manual annotation, or reviewer-labeled samples.
- Explicit dry-run decision surface that implements the playbook decision contract.

## Skill Output
- Back-test results showing whether historical tickets would have been routed correctly, written under `docs/support/playbook-evaluations/` by default.
- Confusion matrix by expected playbook/action versus predicted playbook/action.
- Row-level CSV/XLSX-ready results with ticket id, expected decision, predicted decision, pass/fail, confidence, failure reason, and recommendation fields.
- Failure examples with the ticket id, expected decision, predicted decision, and recommended playbook/prompt improvements.
