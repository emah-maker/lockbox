# FRAIM Skill: facebook-messenger-support-adapter

## Skill Input
- A Facebook Messenger message event payload in the standard `entry[].messaging[]` envelope from the Messenger Platform API. The payload may arrive from a live webhook delivery (Path A: automated queue processing) or be supplied directly by a human operator or attended job for replay or ad-hoc triage (Path B: manual invocation). The skill does not distinguish between the two paths. For Path B, the consuming job is responsible for obtaining the raw payload — either from storage or by fetching the event from the Messenger Platform API using a known `message_id` (`messaging.message.mid`) as a lookup key.

## Skill Output
- A normalized FRAIM support ticket object conforming to the standard ticket abstraction:

```json
{
  "ticket_id": "<uuid-v4>",
  "source": "facebook_messenger",
  "sender_id": "<facebook-psid>",
  "channel_thread_id": "<message-mid>",
  "subject": "<first 80 chars of message text, or '[non-text message]'>",
  "body": "<full message text, or '[non-text message]'>",
  "listing_id": "<referral.ref value, or null>",
  "received_at": "<ISO 8601 UTC timestamp>",
  "intent_hint": "<'other' when body is '[non-text message]', omitted otherwise>",
  "raw": { }
}
```

- For `read`, `delivery`, and `postback` event types: no ticket object is returned and no error is raised.
