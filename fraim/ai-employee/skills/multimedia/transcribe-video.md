# FRAIM Skill: transcribe-video

## Skill Input
- `videoPath` (optional): Absolute path to the `.mp4` recording. Required when no `transcriptPath` or `textTranscript` is provided.
- `transcriptPath` (optional): Path to a `.vtt` or `.srt` file. When provided alongside `videoPath`, used directly instead of attempting audio extraction.
- `textTranscript` (optional): Raw transcript text pasted inline. Supersedes all file-based inputs.
- `sessionContext` (optional): Short description of the recording (e.g., "workflow demo of invoice-generation job"). Used to label the output.

At least one of `videoPath`, `transcriptPath`, or `textTranscript` must be provided.

## Skill Output
- `inputMode`: one of `video-with-vtt` | `video-only` | `vtt-only` | `text-only`
- `transcript`: normalized transcript as an array of `{ timestamp: string | null, speaker: string | null, text: string }` segments. `timestamp` and `speaker` are `null` for plain-text input.
- `durationSeconds` (optional): total recording duration in seconds, when derivable from the VTT or video metadata.
