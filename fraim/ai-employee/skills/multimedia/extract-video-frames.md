# FRAIM Skill: extract-video-frames

## Skill Input
- `videoPath`: Absolute path to the `.mp4` recording.
- `outputDir`: Directory where frame images will be written. Created if it does not exist.
- `sceneThreshold` (optional): ffmpeg scene-change sensitivity, 0.0–1.0 (default: `0.3`). Lower = more sensitive.

## Skill Output
- `frames`: array of `{ timestamp: string, path: string, type: "scene-change" }` objects, sorted by timestamp ascending.
- `frameCount`: total number of frames extracted.
- `scriptPath`: path to the `extract-video-frames.sh` script that was executed (for auditability).
