# FRAIM Skill: incident-command

## Skill Input
- Incident description: initial symptom report, alert that fired, or user-reported issue.
- Severity classification: SEV1–SEV4 based on the severity matrix (or inputs to classify if not yet determined).
- Team roster: available responders with their current role and timezone.
- Current system state: monitoring dashboard links, recent deployments, and any known ongoing changes.

## Skill Output
- **Incident declaration**: Severity level, incident ID, declared-at timestamp, and the incident commander (IC) assignment.
- **Role assignments**: IC, Comms Lead, Tech Lead, and Scribe — each with a named individual and their specific responsibilities for this incident.
- **Investigation workstream**: Timeboxed hypotheses with assigned owners, start time, and expected check-in time.
- **Status page update**: The external-facing status message appropriate for the severity level.
- **Communication cadence**: The schedule for internal updates (war room) and external updates (status page) based on severity.
