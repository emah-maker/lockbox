# FRAIM Skill: blameless-postmortem

## Skill Input
- Incident timeline: the scribe's chronological record of events — alerts fired, actions taken, decisions made, and resolution.
- Impact data: duration of incident, number of affected users or requests, error rate during the incident, and any data loss or corruption.
- System context: the state of the system at the time of the incident — recent deployments, configuration changes, load patterns.
- Mitigation actions taken: what was tried, what worked, what did not work, and in what order.

## Skill Output
- **Postmortem Document**: Structured report with: incident summary, impact statement, timeline, contributing factors, root cause analysis, action items, and lessons learned.
- **Five Whys Analysis**: For the primary contributing factor, a 5-step causal chain from symptom to root cause.
- **Action Items**: Named owner, specific action, and target completion date for each action item. No action item without a named owner.
- **Blameless Language Audit**: Confirmation that the document uses system-level causal language, not individual fault attribution.
