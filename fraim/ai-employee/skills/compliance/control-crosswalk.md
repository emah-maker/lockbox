# FRAIM Skill: control-crosswalk

## Skill Input
- `activeRegulations`: Array of regulation codes the run covers. Supplied by the caller.
- `crosswalkHandbook`: Parsed contents of the crosswalk handbook (caller loads it via `get_fraim_file({path: "data/compliance-crosswalk.yml"})` and passes the parsed object). Contains `control_ids`, `regulation_sources`, `conflicts`, `owasp_to_control_id`.
- `priorRunCrosswalkPath` (optional): Path to a prior run's rendered crosswalk for cache reuse. Supplied by the caller.

## Skill Output
- `crosswalkMatrix`: One row per unique control; columns for each active regulation showing which clause IDs the control satisfies.
- `evidenceReuseMap`: For each control, a canonical evidence-source list that satisfies every mapped regulation (so evidence collected once counts across all mapped regs).
- `conflictFlags`: Controls where two active regulations impose conflicting obligations (e.g., data-minimization vs. long audit-log retention) — emitted with `resolution_required: true`.
