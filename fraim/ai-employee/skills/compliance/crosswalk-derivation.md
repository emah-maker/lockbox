# FRAIM Skill: crosswalk-derivation

## Skill Input
- `activeRegulations`: Array of regulation codes the run covers (e.g. `["soc2", "iso27001", "gdpr"]`).
- `controlIds`: Array of stable control-ids from the handbook (passed in by the caller, not fetched).
- `regulationSources`: Map of regulation code → primary-source URL (passed in by the caller).
- `cacheReadPath` (optional): Path to a prior run's rendered crosswalk whose derivation can be reused if current. Supplied by the caller.

## Skill Output
- `matrix`: Rows of `{control_id, clauses: { <reg>: [clause_ids] }}` for every control × every active regulation.
- `derivationNotes`: Per-row notes where the agent had low confidence or where the primary source was ambiguous.
