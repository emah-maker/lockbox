# FRAIM Skill: dpa-and-vendor-review

## Skill Input
- `document`: A DPA (Data Processing Agreement) document OR a vendor security questionnaire (SIG Lite, CAIQ, or similar).
- `activeRegulations`: Array of regulation codes the run covers. Supplied by the caller.
- `latestEvidenceBundlePath`: Path to the latest `compliance-review-*` bundle to source answers from.

## Skill Output
- `clauseAnalysis`: Clause-by-clause evaluation (for DPAs) with flags `{acceptable, risky, unacceptable, missing}` + recommended redlines.
- `questionnaireResponses`: Per-item answers (for questionnaires) with evidence links, or explicit `unanswered` flags.
