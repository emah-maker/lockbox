# FRAIM Skill: notebooklm-studio-generation

## Skill Input
- `documentPaths`: Array of absolute file paths to documents (PDF, images, docs, audio) to use as notebook sources.
- `outputType`: Studio artifact to generate — one of: `audio`, `slides`, `video`, `mindmap`, `report`, `flashcards`, `quiz`, `infographic`, `data-table`.
- `notebookTitle` (optional): Custom title for the NotebookLM notebook. If omitted, NotebookLM auto-generates one from sources.
- `customInstructions` (optional): Focus area or angle for the generated artifact.

## Skill Output
- A NotebookLM notebook with all sources uploaded and the requested Studio artifact generation triggered.
- The notebook URL for the user to access, download, or share the output.
