# FRAIM Skill: analyze-transcript

## Skill Input
- `transcript`: Raw transcript text (pasted block, multi-speaker dialogue, or read from a file path).
- `sessionContext` (optional): A short description of the session type (e.g., "customer development interview", "technical design review"). Influences categorization tone and weighting.
- `outputMode` (optional): One of `notes` (default), `ashley-tasks`, or `learning-entry`.

## Skill Output
- A markdown document with three sections:
  - **Items Learned** — factual takeaways and confirmations grounded in the transcript.
  - **Actionable Items** — next steps, commitments, and task assignments (with owner and deadline when mentioned).
  - **Other Important Notes** — decisions, blockers, risks, and open questions.
- When `outputMode` is `ashley-tasks`: Actionable Items section also includes Ashley-formatted task blocks.
- When `outputMode` is `learning-entry`: Items Learned section also includes FRAIM coaching-moment candidate blocks.
