# FRAIM Skill: ip-assignment-coverage-check

## Skill Input
- A list of everyone who has done measurable work on the company: founders, employees, contractors, freelancers, designers, advisors, agencies.
- Existing signed agreements on file (per person, if any).
- The company entity (assignee) and jurisdiction.

## Skill Output
- A **coverage matrix**: each contributor × whether a valid IP-assignment (and, for employees/founders, a CIIA) is signed and on file.
- The **gap list**: contributors who created IP without a signed assignment — the legal exposure to close.
- Per-gap recommendation: the right instrument (CIIA for founders/employees; IP-assignment clause/agreement for contractors; work-for-hire where applicable) and signing order by risk.
- Items requiring counsel.
