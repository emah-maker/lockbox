# FRAIM Skill: w9-form-filling

## Skill Input
- `operation`: One of `validate-fields`, `recommend-mapping`, `map-fields`, `fill-pdf`, `quality-check`.
- `officialW9TemplatePath`: Local path to official IRS `fw9.pdf`.
- `w9Data`: Structured W-9 values:
  - `ownerName`
  - `legalEntityName`
  - `businessName` (optional)
  - `federalTaxClassification`
  - `llcTaxElection` (required only when LLC is checked with C/S/P treatment)
  - `singleMemberIndicator` (optional but recommended)
  - `entityElectionEvidence` (optional: evidence of 8832/2553 or equivalent)
  - `addressLine1`
  - `cityStateZip`
  - `requesterNameAddress` (optional)
  - `tinType`
  - `tinValue` (optional if intentionally deferred for manual entry)
  - `authorizedSignerName`
  - `signatureDate` (optional if intentionally deferred for manual signature)
  - `line1Strategy` (`owner-name` or `entity-name`)
  - `allowSensitiveManualEntry` (boolean)
- `w9FieldMap` (optional for `fill-pdf`): Precomputed field map.
- `outputFilledW9Path` (required for `fill-pdf`).
- `backupPath` (optional): Backup destination before overwrite.

## Skill Output
- `validationFlags`: Missing, conflicting, or high-risk values.
- `mappingRecommendation`: Recommended line-1/line-2/TIN mapping with rationale.
- `w9FieldMap`: Deterministic official PDF field map.
- `completionChecklist`: Final readiness and unresolved manual actions.
- `filledW9PdfPath`: Generated output PDF path.
- `qualityCheckResult`: Pass/fail with detailed reasons.
