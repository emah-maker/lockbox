# FRAIM Skill: counterparty-ready-redline-production

## Skill Input
- `sourceDocumentPath`: Original contract path in PDF, DOCX, Markdown, text, or another available format.
- `documentContext`: Output from `document-intake-and-context-analysis`, including parties, deal context, source format, and review objectives.
- `prioritizedRecommendations`: Output from `risk-prioritization-and-recommendations`, categorized as must-have, should-have, and nice-to-have.
- `reviewReport`: Internal report from `review-summary-and-action-plan`, when available.
- `redlinePosture`: Optional posture of `minimal`, `balanced`, or `aggressive`; default is `minimal`.
- `outputMode`: Optional mode of `review-report`, `sendback-redline`, or `both`; infer from the user request when omitted.

## Skill Output
- `redlineDecision`: Whether a counterparty-ready redline is needed and why.
- `externalEditSet`: Minimal set of user-protective changes selected for counterparty review.
- `omittedInternalFindings`: Valid internal findings intentionally omitted from the send-back redline because they are not material enough for the negotiation posture.
- `redlineDocxPath`: Path to the editable DOCX redline when `sendback-redline` or `both` is selected.
- `verificationSummary`: Evidence that the DOCX was structurally checked and, when tooling permits, rendered or opened for visual QA.
