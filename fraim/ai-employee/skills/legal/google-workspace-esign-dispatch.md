# FRAIM Skill: google-workspace-esign-dispatch

## Skill Input
- `documentPath`: Final document that needs e-signature.
- `sendAssetPath`: Optional already-rendered Google-friendly asset such as PDF or DOCX.
- `documentTitle`: Human-readable document title used in the manifest and outbound request.
- `signers`: Ordered list of signer objects with `name`, `email`, optional `role`, and optional `fields`.
- `recipientName` and `recipientEmail`: Backward-compatible single-signer inputs that should be normalized into `signers[0]` when present.
- `signerFields`: Shared fields the signer must complete before signing.
- `ccEmails`: Optional list of additional recipients.
- `message`: Optional outbound message to include in the Google request.
- `manifestPath`: Path to the dispatch manifest file.

## Skill Output
- `dispatchManifest`: Updated manifest with normalized signer data, send asset path, send status, Google request link, and verification notes when available.
- `sendResult`: Whether the Google Workspace eSignature request was prepared, sent, verified, or handed off for manual completion.
