# FRAIM Skill: eas-build-pipeline

## Skill Input
- An Expo / React Native project with `app.config.ts` (or `app.json`) and `eas.json` configured
- An EAS account with the project linked, valid Apple Developer credentials registered, and (for auto-submit) a configured ASC API key
- A target build profile (`development`, `preview`, `preview-simulator`, `production`)
- Target platform (`ios`, `android`, or both)
- Whether to auto-submit on success

## Skill Output
- A successfully built and (optionally) submitted artifact with:
  - Unique, monotonically increasing build number (auto-incremented)
  - Build ID for traceability
  - IPA / AAB artifact URL
  - For auto-submit: ASC submission ID and confirmation that the binary uploaded successfully
