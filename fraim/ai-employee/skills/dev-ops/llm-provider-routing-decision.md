# FRAIM Skill: llm-provider-routing-decision

## Skill Input
- `llm_providers_in_use` — the list from `llm-spend-detection`. Each entry is `(provider, agent_or_app)`.
- `clouds_with_credits` — which of `aws`, `gcp`, `azure` the user has unused credits in.
- `priority` — one of `cost-only`, `latency`, `feature-parity`. Default `cost-only` (most users invoking this job want their credits absorbed).

## Skill Output
A single decision per LLM-provider currently in use: which cloud and which cloud-hosted equivalent to route to, with rationale. If multiple clouds are viable, pick one and call out the alternatives explicitly.
