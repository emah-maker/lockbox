# FRAIM Skill: android-app-bundle-build

## Skill Input
- Source tree at the chosen toolchain (Gradle / EAS / Flutter)
- Signing config: upload keystore + credentials, or EAS-managed credentials
- Build variant target (`release` for Play Store; `staging` for internal testing)
- Versioning rules (`versionCode` is monotonically increasing integer; `versionName` is the human string)

## Skill Output
- A signed `.aab` (Android App Bundle) at a known path, ready for the `play-store-submission` job to upload.
- A `bundletool`-extracted `.apks` set used to validate device-specific splits before upload.
- A `mapping.txt` for R8 deobfuscation, ready to attach to the Play Console release.
