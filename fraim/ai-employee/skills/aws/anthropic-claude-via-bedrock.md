# FRAIM Skill: anthropic-claude-via-bedrock

## Skill Input
- `aws_account_id` — the account where Bedrock should be enabled and where credits will be consumed. Must already exist on a paid plan and have IAM access.
- `region` — the AWS region to use for cross-region inference. Default: `us-east-1` (no premium for Opus 4.7; broadest model availability).
- `models_required` — list of Anthropic models you plan to invoke (e.g., `["claude-opus-4-7", "claude-sonnet-4-6", "claude-haiku-4-5-20251001-v1:0"]`).
- `agent` — which agent will be the consumer (`claude-code`, `aider`, etc.).

## Skill Output
A working AWS Bedrock setup that the chosen agent (and any Anthropic SDK code) can reach via cross-region inference profiles. Specifically:
- Anthropic models enabled on `aws_account_id` (use case submitted)
- A long-term Bedrock API key stored at `$HOME/.aws-bedrock/bedrock-long-term-api-key.csv` (outside any repo)
- Confirmation that quota for the requested models is non-zero (or a support case filed if it isn't)
- Runtime configuration inputs captured for the consuming agent (profile, flip script, or config patch can be derived from these facts later)
