# FRAIM Skill: aws-performance-data-collection

## Skill Input
- `targetResources`: List of AWS resource ARNs / IDs under investigation (EC2 instances, Lambda functions, RDS instances, ECS services, ALB target groups).
- `timeRange`: Start and end timestamps (ISO 8601) for the diagnostic window.
- `collectLogs`: Boolean — whether to retrieve CloudWatch log groups in addition to metrics.

## Skill Output
- `metrics`: CloudWatch metric series (CPU, Memory, NetworkIn/Out, IOPS, latency, error rate) keyed by resource.
- `traces`: X-Ray trace summaries for the most recent N traces (when X-Ray is enabled on the resource).
- `logs`: Filtered CloudWatch log entries containing performance-relevant patterns (timeouts, OOMs, throttles).
