# FRAIM Skill: company-handle-strategy

## Skill Input
- `companyName`: The legal or operating name of the company.
- `brandSystem` (optional): Brand system artifact at `docs/branding/brand-system/` if it exists.
- `primaryDomain` (optional): Registered domain from domain-registration-research.
- `targetPlatforms`: Array of platforms to reserve handles on (e.g. `linkedin`, `x`, `github`, `instagram`, `youtube`).

## Skill Output
- `handleRecommendations`: Ordered list of preferred handles per platform with rationale.
- `availabilityMatrix`: Availability status of each candidate handle on each target platform.

- `reservationPlan`: Recommended order of reservation given platform-specific claim rules.
