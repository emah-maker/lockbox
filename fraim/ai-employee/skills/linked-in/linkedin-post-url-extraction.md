# FRAIM Skill: linkedin-post-url-extraction

## Skill Input
- Current workflow context and required source material.

## Skill Output
- Direct LinkedIn post URL matching one of these shapes:
  - `https://www.linkedin.com/feed/update/urn:li:activity:<id>` (feed posts)
  - `https://www.linkedin.com/posts/<slug>-activity-<id>-<token>/` (shared posts)
  - `https://www.linkedin.com/pulse/<slug>/` (long-form articles)
  Anything matching `https://www.linkedin.com/in/<handle>` (profile) is a failure.
