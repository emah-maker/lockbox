# FRAIM Skill: linkedin-company-page-creation

## Skill Input
- `companyName`: Exact display name to set on the page.
- `primaryDomain`: Registered company domain.
- `vanityHandle`: Preferred LinkedIn vanity URL (e.g. `linkedin.com/company/{handle}`).
- `assetChecklist`: Output of `profile-asset-preparation` for LinkedIn with logo and cover paths plus copy drafts.
- `industryTaxonomy`: LinkedIn industry category for the company.
- `companySize`: LinkedIn company size bucket.
- `adminProfiles`: List of LinkedIn profile URLs for Super Admins, Content Admins, and Analysts.

## Skill Output
- `pageUrl`: Live `linkedin.com/company/{handle}` URL after creation.
- `dnsVerificationRecord` (conditional): TXT record value LinkedIn generates — only if the manager opted into the paid Premium Page subscription. As of 2026 LinkedIn has removed free DNS TXT verification for Company Pages; the "verification badge" is gated behind a paid subscription. Returns `null` in the default (free-tier) path.
- `adminInviteStatuses`: For each admin, the invite delivery state.
- `executionLog`: Ordered action log with UI snapshots at each decision point.
