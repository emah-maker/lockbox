# FRAIM Skill: app-store-listing-copy

## Skill Input
- The product spec or one-liner positioning
- The landing-page copy from the marketing website
- The store's char-limit table (Apple: subtitle 30 / promo 170 / keywords 100 / description 4000; Google Play: short 80 / full 4000)
- The legal entity name (for copyright field)
- A list of differentiators that distinguish this app from generic templates (Apple Guideline 4.3 protection)

## Skill Output
- All listing copy fields filled at or under each store's char limits:
  - App Name (with uniqueness pre-check vs the store's catalog)
  - Subtitle / Short Description
  - Promotional Text / Highlight
  - Description / Full Description (~1500-3500 chars typical)
  - Keywords (comma-separated, no spaces around commas)
  - Support URL
  - Marketing URL
  - Copyright (with the canonical legal entity)
