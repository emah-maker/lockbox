# FRAIM Skill: prospect-entity-discovery

## Skill Input
- `fundingType`: One of [VC, Angel, Crowdfunding, Grant, Startup-Credits].
- `verticals`: List of industry sectors (e.g., [AI, ClimateTech, SaaS]).
- `stage`: Target funding stage (e.g., Pre-seed, Seed, Growth).
- `minFundingGoal`: Numerical target (e.g., $50,000 for Crowdfunding).
- `geography`: Target region (e.g., Global, US, EU).

## Skill Output
- `entityProspects`: A structured list of potential funding sources including:
  - `entityName`: Name of the VC firm, platform, or grant.
  - `profileUrl`: Official website or platform link.
  - `recentActivity`: Summary of last 3 investments or active campaigns in this vertical.
  - `entryMechanism`: Contact email, application portal link, or "Cold Outreach" status.
