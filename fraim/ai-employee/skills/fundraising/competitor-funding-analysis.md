# FRAIM Skill: competitor-funding-analysis

## Skill Input
- `competitorList`: 3-5 confirmed competitors in the same space.
- `discoveryDepth`: [Surface, Deep Scan].

## Skill Output
- `competitorFundingMap`: A mapping for each competitor:
  - `competitorName`: Entity name.
  - `leadInvestors`: List of firms that led their rounds.
  - `roundSize`: Most recent disclosed funding amount.
  - `opportunityStatus`: Boolean (True if the investor typically invests in multiple competitors; False if they have an exclusivity preference).
