# FRAIM Skill: investment-thesis-alignment

## Skill Input
- `projectArtifacts`: The pitch deck, executive summary, or product spec.
- `investorIntelligence`: Scraped data from the investor's website, blog posts, or profile.
- `targetOutcome`: The specific reason for the pitch (e.g., "Equity Seed Round").

## Skill Output
- `alignmentReport`: A JSON analysis containing:
  - `fitScore`: 1-10 based on criteria match.
  - `matchingPillars`: List of aspects where the project aligns perfectly with the thesis.
  - `frictionPoints`: List of aspects that might cause the investor to pass.
  - `reframingAdvice`: Suggestions on how to pivot the narrative to better fit this specific entity.
