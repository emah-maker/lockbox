# FRAIM Skill: secrets-in-code-check

## Skill Input
- `reviewScope`: One of `{repo, directory, branch, pr, diff}`.
- `surfaceAreaPaths`: The files or directories under review.
- `diff` (optional): The PR / branch diff when the review is incremental.
- Repository root path.

## Skill Output
- Findings with `owasp_code: "SEC-LEAK"`.
- Severity is always **Critical** for a production-looking secret; **Low** for an obvious placeholder (`example`, `test`, `changeme`, `dummy`, `placeholder` prefix).
