# FRAIM Skill: finding-disposition

## Skill Input
- A finding object (from any OWASP/privacy/secrets skill) with `severity`, `owasp_code`, `file`, `line`, `evidence`.
- The full set of findings for this run (needed for the auto-fix cap).
- Run configuration: whether GitHub credentials are available, whether this is a re-run.

## Skill Output
- `disposition`: one of `fix`, `file`, `accept`.
- `auth_crypto_touched`: boolean (forces `file` when true).
- `fix_patch` (only when `disposition = fix`): exact file edits to apply.
- `rationale`: one-line reason for the chosen disposition.
