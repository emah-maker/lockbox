# FRAIM Skill: compliance-control-mapping-security

## Skill Input
- `finding`: A finding object with an `owasp_code` (e.g. `A01`, `API07`, `LLM01`, `SEC-LEAK`, `PRIV03`).
- `activeRegulations`: Array of regulation codes the project targets (e.g. `["soc2", "iso27001"]`). Supplied by the caller.
- `crosswalkHandbook`: Parsed contents of `data/compliance-crosswalk.yml`. Supplied by the caller.

## Skill Output
- `control_ids`: One or more stable control-ids the finding touches (from `crosswalkHandbook.owasp_to_control_id[finding.owasp_code]`).
- `compliance`: `{ <regulation_code>: [clause_ids] }` populated only for regulations in `activeRegulations`, with clauses derived on demand.
