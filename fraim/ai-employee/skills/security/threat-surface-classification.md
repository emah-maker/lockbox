# FRAIM Skill: threat-surface-classification

## Skill Input
- `reviewScope`: One of `{repo, directory, branch, pr, diff}`.
- `surfaceAreaPaths`: The explicit file paths or directory roots under review.
- A git diff (from `git diff origin/<base>...HEAD` or equivalent) when `reviewScope = diff`, or when a branch / PR review wants change-aware evidence in addition to whole-scope classification.
- Repository root path.

## Skill Output
- `surfaces`: Array of detected surfaces from the closed set `{web, api, llm-app, data-pipeline, mobile, capability-authoring, docs-only}`.
- `rationale`: Per-surface list of (file, heuristic) matches explaining why each surface applied.
- `reviewedPaths`: The normalized file set actually used for classification.
