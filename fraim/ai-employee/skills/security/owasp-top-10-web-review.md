# FRAIM Skill: owasp-top-10-web-review

## Skill Input
- `reviewScope`: One of `{repo, directory, branch, pr, diff}`.
- `surfaceAreaPaths`: The web-surface files or directories under review.
- `diff` (optional): The PR / branch diff when the review is incremental or when change-aware evidence should be prioritized.
- `projectGotchas` (optional): Project-specific quirks that change the default OWASP interpretation - for example the project's actual auth directory, fixture paths that intentionally ship insecure patterns, or known false-positive shapes. Populated over time via retrospective.

## Skill Output
- `findings`: Array of findings per the `security-review` finding schema (`id`, `severity`, `owasp_code` in `A01..A10`, `file`, `line`, `message`, `recommendation`, `evidence`).
- `coverage`: One row per OWASP Top 10 (web) category with status `{Pass, Fail, N/A, Error}`.
