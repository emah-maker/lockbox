# FRAIM Skill: mobile-app-screenshot-generation

## Skill Input
- A running mobile app (or a web preview of the app's UI, e.g., Expo Web for React Native)
- The destination store's required device-class spec table (Apple iPhone 6.9" = 1290×2796, Google Play 1080×1920 / 1080×2400, Microsoft Store varies)
- A list of UI states to capture (onboarding, hero card, primary feature, secondary feature, etc.)
- Optional: brand-colored / populated demo data so the screenshots demonstrate real content (Apple Guideline 4.3 differentiation; Google Play "misleading content" prevention)

## Skill Output
- One PNG per device-class × UI-state combination, at exact pixel dimensions, ready for upload to App Store Connect Media Manager / Google Play Console / Microsoft Store.
- A side-by-side index image (optional) showing the upload order for the store carousel.
