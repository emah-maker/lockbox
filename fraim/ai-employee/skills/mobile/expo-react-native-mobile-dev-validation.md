# FRAIM Skill: expo-react-native-mobile-dev-validation

## Skill Input
- A React Native / Expo project (SDK 54+) with Metro bundler available or an EAS build in progress
- A Windows 11 development machine with Android SDK installed at `%LOCALAPPDATA%\Android\Sdk`
- The target tab or screen to validate after a UI change or before advancing to `deployment`

## Skill Output
- Confirmation that Metro starts clean (no HTTP 500), the app loads past splash on emulator, the target tab/screen is visible and correct
- ADB logcat diagnosis report if a blank screen or crash is observed, identifying the root cause
- EAS build ID and TestFlight submission status when deployment is in scope
