# FRAIM Skill: capability-candidate-discovery

## Skill Input
- `capabilityRequest`: The behavior or capability to add/refine.
- `localRoot`: Local override root to scan (for example `fraim/personalized-employee/`).
- `baselineRoot`: Synced baseline root to scan (for example `ai-employee/`).
- `assetKinds` (optional): Which asset types to include (`jobs`, `skills`, `rules`).

## Skill Output
- `candidateLocalAssets`: Ranked local candidates that may satisfy the request.
- `candidateBaselineAssets`: Ranked baseline candidates that may satisfy the request.
- `discoverySummary`:
  - what was searched
  - strongest matches
  - nearest job by semantic Intent/Outcome fit
  - obvious gaps (if no high-fit candidate exists).
