# FRAIM Skill: evolution-intent-classification

## Skill Input
- `managerRequest`: The manager's plain-language description of what should change.
- `currentBehavior`: What the employee does today.
- `desiredBehavior`: What the employee should do instead.
- `examples` (optional): Good or bad examples supplied by the manager.
- `qualityExpectations` (optional): Reliability, approval, verification, or format expectations.

## Skill Output
- `primaryIntent`: One of `customize`, `teach`, `correct`, or `adapt`.
- `secondaryIntents` (optional): Additional intent tags when the request is mixed.
- `intentSummary`: Plain-language explanation of why the classification fits.
- `qualityModifier`: Any reliability or review hardening that should apply across the intervention.
- `remainingUnknowns`: The smallest set of unanswered questions still needed before planning.
