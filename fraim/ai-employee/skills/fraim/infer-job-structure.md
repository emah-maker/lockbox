# FRAIM Skill: infer-job-structure

## Skill Input
- `transcript`: normalized transcript array from the `transcribe-video` skill — `{ timestamp, speaker, text }[]`.
- `frames` (optional): frame list from the `extract-video-frames` skill — `{ timestamp, path, type }[]`. When provided, used to correlate screen state with speech.
- `demoContext` (optional): short description of what workflow is being demonstrated (e.g., "invoice generation workflow for a legal services firm"). Helps ground Intent extraction.

## Skill Output
A draft FRAIM job structure object:
```
{
  intent: string,
  outcome: string[],
  phases: { name: string, summary: string, steps: string[] }[],
  skillsObserved: string[],
  gaps: string[]
}
```
- `intent`: one-sentence business intent, leading with the user's outcome (not agent actions).
- `outcome`: bullet list of deliverables the job produces.
- `phases`: ordered list of workflow phases inferred from the demo, each with a kebab-case name, a one-line summary, and concrete steps.
- `skillsObserved`: names of any FRAIM skills, tools, or systems referenced or visible on screen.
- `gaps`: list of questions the agent could not answer from the recording (e.g., "Intent is unclear — demo shows steps but not the business goal").
