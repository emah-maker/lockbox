# FRAIM Skill: teach-seed-intake

## Skill Input
- `seedSource`: One of `completed-run`, `document`, or `description`.
- `runTranscript` (when `seedSource` is `completed-run`): the manager and employee turns, the steps actually performed, the org-specific coaching the manager added, and the artifacts produced.
- `documentRef` (when `seedSource` is `document`): a path or reference to an SOP or procedure document.
- `managerDescription` (when `seedSource` is `description`): the manager's plain-language description of the capability.
- `existingJob` (optional): the structured job a `completed-run` seed was produced by, when the run executed a catalog job the manager coached.

## Skill Output
- `prefilledIntake`: a draft intake the manager confirms or edits, never re-describes from scratch. Includes the ask, the steps, the artifacts/deliverable, and a proposed job name (teach) or the existing job name (customize).
- `phaseMapping` (document seeds): how the document's sections and steps map onto job phases and phase steps.
- `semanticJobFit` (document and description seeds): nearest existing job candidates by Intent/Outcome fit, and whether one already owns the workflow.
- `seedMode`: `teach` (net-new job) or `customize` (improve `existingJob`).
- `missingInfo`: targeted questions when the seed is too thin to generalize.
