# FRAIM Skill: recommend-next-job

## Skill Input
- User request for next-step recommendations, a prerequisite scan, or journey progress
- Context about the completed job (if any)
- User's segment (founder, enterprise, consultant, agency) and journey stage (gather these)
- Optional target job name when the user wants to check readiness to run a specific job

## Skill Output
One of three shapes, per the requested mode:
1. **Forward recommendation**: 2-3 specific FRAIM jobs with rationale and a reference to the segment guide.
2. **Backward prerequisite scan**: a readiness report for a target job, each upstream prerequisite marked Complete / Partial / Missing, plus a recommendation.
3. **Journey dashboard**: a stage-by-stage summary of which journey jobs have produced artifacts and which have not.
Every output references the relevant guide section and explains why each recommendation or warning was produced.
