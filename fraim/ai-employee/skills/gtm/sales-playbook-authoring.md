# FRAIM Skill: sales-playbook-authoring

## Skill Input
- ICP profile list: 1–3 ICP clusters with company attributes, buyer titles, and ACV range.
- Motion type per ICP: PLG, sales-assisted PLG, or outbound enterprise.
- Bowtie journey map (optional): existing `docs/gtm/gtm-system-design-*.md` stage definitions.
- Objection data (optional): closed-lost reasons, call transcript excerpts, or representative objection themes.
- Existing playbook artifacts (optional): any prior outreach sequences, discovery scripts, or objection guides.
- Playbook scope: one or more of `outreach`, `discovery`, `objections`, `expansion`.

## Skill Output
- **Outreach sequences** (scope: `outreach`): per-ICP multi-touch sequence with ≥3 touches across ≥2 channels. Each touch specifies: day offset, channel (email/LinkedIn/call/text), subject line or talk track opening, body, and call-to-action. No generic templates — every touch references at least one ICP-specific attribute (industry, use case, or buyer pain).
- **SPICED discovery framework** (scope: `discovery`): a structured discovery script for each ICP covering all 5 SPICED dimensions (Situation, Pain, Impact, Critical Event, Expected Outcome). Each dimension: ≥2 open-ended question variants, a signal of a strong vs. weak answer, and a note on when the dimension is typically missing at deal loss. Includes a qualification gate: minimum SPICED completeness required before advancing to Validate.
- **Objection guide** (scope: `objections`): ≥3 recurring objection patterns with: the exact language pattern, the SPICED dimension it signals as missing, a reframe response, and a follow-up question. When objection data is provided as input, patterns must be grounded in that data. When no data is provided, flag as "representative — validate against closed-lost data."
- **Expansion playbook** (scope: `expansion`): ≥2 expansion trigger signals with the corresponding seller action and talk track. For PLG motions, includes activation journey touch points, lifecycle email triggers, and SDR handoff criteria.
