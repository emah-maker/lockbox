# FRAIM Job: brand-creation

## Intent
Create or materially strengthen a brand using one coherent workflow that can support new-brand creation, repositioning, rebrand work, product-brand work, founder-brand work, employer-brand work, and portfolio/architecture needs without fragmenting the catalog into many separate branding jobs.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/branding/brand-system/{slug}-{YYYY-MM-DD}.docx with brand core definition, positioning statement, differentiation logic, messaging system, and optional modules (naming, identity brief, architecture, governance, rebrand migration notes)
- A brand system that includes brand core, positioning, differentiation, messaging, and downstream execution guidance
- Optional output modules for naming, identity briefing, architecture recommendations, governance starter guidance, and rebrand migration notes

## Steps
1. Phase 1: `context-synthesis`
2. Phase 2: `audience-and-market-framing`
3. Phase 3: `brand-core-definition`
4. Phase 4: `positioning-and-differentiation`
5. Phase 5: `messaging-system`
6. Phase 6: `optional-modules`
7. Phase 7: `brand-system-output`
8. Phase 8: `address-feedback`
9. Phase 9: `retrospective`
