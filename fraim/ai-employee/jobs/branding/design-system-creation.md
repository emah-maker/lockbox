# FRAIM Job: design-system-creation

## Intent
Create or strengthen the reusable design system that downstream product surfaces, prototypes, and websites should extend instead of reinventing.

## Outcome
- **Reviewable deliverable**: A living HTML/CSS reference document at `docs/design-system/{slug}.html` containing rendered foundational tokens (color, typography, spacing, radius, elevation, motion), component library with usage rules and anti-patterns, page-level patterns, and a durable example surface demonstrating system application. A design system is referenced and used — not presented as slides.
- Baseline design-system artifact under `docs/design-system/`
- Defined tokens for color, type, spacing, elevation, and motion
- Reusable component and layout rules for the target surface family
- At least one durable example surface or specimen showing the system applied
- Explicit downstream usage guidance for prototypes, websites, and product-facing UI work

## Steps
1. Phase 1: `design-system-context`
2. Phase 2: `design-system-foundations`
3. Phase 3: `design-system-patterns`
4. Phase 4: `design-system-documentation`
5. Phase 5: `submit`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
