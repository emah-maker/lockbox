# FRAIM Job: ux-research-synthesis

## Intent
Run a structured usability test cycle — from participant recruitment through session execution, task scoring, and insight synthesis — producing actionable design recommendations grounded in observed user behavior.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/design/{date}-ux-research-synthesis-{YYYY-MM-DD}.pptx containing test protocol summary, task completion rates, usability issues with severity scoring matrix, key findings and mental model insights, and prioritized design recommendations with effort estimates
- **Test Protocol**: Defined tasks, success criteria, and observer guidelines.
- **Usability Scores**: Task completion rates and severity-scored usability issues.
- **Design Recommendations**: Prioritized recommendations grounded in observed failure patterns.

## Steps
1. Phase 1: `recruitment`
2. Phase 2: `test-execution`
3. Phase 3: `scoring`
4. Phase 4: `insight-synthesis`
5. Phase 5: `ux-research-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
