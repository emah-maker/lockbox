# FRAIM Job: tracking-and-attribution-setup

## Intent
Audit and implement a clean tracking stack — UTM conventions, conversion event instrumentation, and attribution model configuration — so marketing spend can be measured accurately and optimized with confidence.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/marketing/tracking/{date}-tracking-setup.docx with UTM Taxonomy (standardized parameter conventions), Conversion Events (instrumented events per funnel stage with server-side backup), Attribution Model (selected model with rationale and configuration), and Validation Report (confirmed end-to-end data flow).
- **UTM Taxonomy**: Standardized UTM parameter conventions for all channels.
- **Conversion Events**: Instrumented conversion events for each funnel stage with server-side backup where applicable.
- **Attribution Model**: Selected and documented attribution model with configuration steps.
- **Validation Report**: Confirmed data flow from ad click to CRM record.

2. Phase 2: `utm-setup`

4. Phase 4: `attribution-model-selection`
5. Phase 5: `validation`
