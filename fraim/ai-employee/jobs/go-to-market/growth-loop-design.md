# FRAIM Job: growth-loop-design

## Intent
Design a viral, referral, or content growth loop for a specified product surface, complete with a k-factor estimate and an instrumentation plan so the team can build and measure it immediately.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/gtm/growth-loop-{YYYY-MM-DD}.docx with Anchor Action definition, Loop Structure Diagram (input trigger, propagation, reward, re-entry), K-Factor Estimate with sensitivity table, Instrumentation Plan with event schema, and Primary/Fallback Variants.
- **Anchor Action**: The specific product surface or user behavior the loop is built around.
- **Loop Structure Diagram**: Input trigger → propagation mechanism → reward → re-entry, described in full.
- **K-Factor Estimate**: Loop coefficient calculated from referral rate data (or estimated from benchmarks if data is unavailable).
- **Instrumentation Plan**: A list of events to track, with schema, to measure loop performance in production.
- **Primary and Fallback Variants**: One recommended loop to build first, plus a simpler fallback if the primary is too complex.

## Steps
1. Phase 1: `identify-anchor-action`
2. Phase 2: `define-loop-structure`
3. Phase 3: `estimate-k-factor`
4. Phase 4: `specify-instrumentation`
5. Phase 5: `submit`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
