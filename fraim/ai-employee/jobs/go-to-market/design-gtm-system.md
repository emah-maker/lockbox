# FRAIM Job: design-gtm-system

## Intent
Design a per-ICP, per-segment GTM system using the Winning by Design Bowtie model — mapping the full customer lifecycle from Educate through Advocate for each priority ICP, with a motion type recommendation and channel strategy per segment.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/gtm/gtm-system-design-{YYYY-MM-DD}.pptx containing Per-ICP Bowtie Journey Maps (all 9 stages), Bowtie Knot Definition (Sales-CS handoff), Motion Type Recommendation per ICP with rationale, and Channel Strategy (≥2 channels per ICP with pipeline contribution estimates).
- **Per-ICP Bowtie Journey Maps**: Full 9-stage Bowtie (Educate, Engage, Validate, Sign, Onboard, Adopt, Expand, Renew, Advocate) with entry criteria, exit criteria, buyer action, seller/CS action, and failure mode for each stage.
- **Bowtie Knot Definition**: Explicit Sales→CS handoff at the Sign stage for each ICP.
- **Motion Type Recommendation**: PLG, sales-assisted PLG, or outbound enterprise per ICP with rationale.
- **Channel Strategy**: ≥2 channels per ICP with estimated pipeline contribution.

## Steps
1. Phase 1: `define-icp-profiles`
2. Phase 2: `map-bowtie-journeys`
3. Phase 3: `define-motion-and-channels`
4. Phase 4: `produce-gtm-system-design`
5. Phase 5: `submit`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
