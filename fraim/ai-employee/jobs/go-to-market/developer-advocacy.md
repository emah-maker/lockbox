# FRAIM Job: developer-advocacy

## Intent
Build a developer advocacy program that improves developer experience, sets community response SLAs, and designs an ambassador program — reducing time-to-first-success for developers and building external champions who drive organic growth.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/marketing/developer-advocacy/{date}-devrel-program.docx with DX Audit findings, Community SLAs (response times per channel), Ambassador Program Design (tiers, selection criteria, enablement, recognition), and 90-Day Implementation Roadmap.
- **DX Audit**: Assessment of the developer experience from first-contact to first-success with friction points identified.
- **Community SLAs**: Defined response time SLAs for GitHub issues, Discord/Slack, Stack Overflow, and forum posts.
- **Ambassador Program Design**: Framework for identifying, recruiting, and enabling external developer champions.

## Steps
1. Phase 1: `dx-audit`
2. Phase 2: `community-sla-definition`
3. Phase 3: `ambassador-design`
4. Phase 4: `report`
5. Phase 5: `developer-advocacy-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
