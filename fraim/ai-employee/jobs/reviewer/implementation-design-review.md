# FRAIM Job: implementation-design-review

## Intent
To systematically verify that the implementation matches the approved technical design (RFC), ensuring **completeness**, **correctness**, and **quality** of all technical requirements, test cases, and validation scenarios.

## Outcome
- Final artifact: A single review report at `docs/evidence/{issue}-design-review.md` with `decision` and `iteration` frontmatter and round-by-round findings.
- **Approved Implementation**: Confirmation that the code meets RFC standards.
- **Actionable Feedback**: Clear guidance for implementation agents if changes are needed.
