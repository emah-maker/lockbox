# FRAIM Job: codebase-analysis-and-ideation

## Intent
Provide a structured approach for analyzing an existing codebase and generating grounded, evidence-based improvement ideas. Ask: *"What **can** we build or improve based on what we actually have?"* (Bottom-up, technical reality). Strict accuracy is enforced — fabricating non-existent functionality is not tolerated.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/brainstorming/codebase-brainstorming-{YYYY-MM-DD}.pptx with sections for Currently Exists (with file paths), Architectural Patterns, Gaps and Opportunities, and Actionable Suggestions (grounded improvement ideas with evidence traces).
- **Accurate Inventory**: A clear distinction between what exists and what could be built, with every claim traceable to a file path.
- **Actionable Suggestions**: Realistic, incremental improvement ideas ready for conversion into implementation issues.

## Steps
1. Phase 1: `codebase-analysis`
2. Phase 2: `categorized-analysis`
3. Phase 3: `grounded-suggestions`
4. Phase 4: `verification-and-validation`
5. Phase 5: `codebase-ideation-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
