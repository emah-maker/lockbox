# FRAIM Job: sf-config-deployment

## Intent
Translate ServiceNow change tickets into Salesforce configuration changes — deploying custom fields, objects, validation rules, and permission sets via the Metadata API — and update the ServiceNow ticket with the deployment result.

## Outcome
- **Reviewable deliverable:** A .docx document at docs/salesforce/sf-config-deployment-{YYYY-MM-DD}.docx with ServiceNow ticket details, Salesforce configuration intent, deployment results, validation findings, and drift detection report
- Salesforce configuration deployed and validated
- Drift detection report comparing intended vs. actual SF state
- ServiceNow change ticket updated with deployment status

## Steps
1. Phase 1: `read-change-ticket`
2. Phase 2: `translate-to-sf-config`
3. Phase 3: `deploy-and-validate`
4. Phase 4: `detect-drift`
5. Phase 5: `update-snow-ticket`
6. Phase 6: `produce-summary`
7. Phase 7: `submit`
