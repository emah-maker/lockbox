# FRAIM Job: sf-org-health-check

## Intent
Audit the Salesforce org's health across governor limits, API consumption, storage, security posture, and automation inventory — and surface the top risks before they become outages.

## Outcome
- **Reviewable deliverable:** A .pptx presentation at docs/salesforce/sf-org-health-check-{YYYY-MM-DD}.pptx containing governor limits utilization tables, API consumption trends, storage projections, security risk summaries, automation inventory, and health score scorecards
- Governor limits utilization report with red/amber/green status per limit
- API daily request consumption and trend (7-day rolling)
- Data and file storage utilization with projected fill date
- Security health: inactive users with active sessions, profiles with broad permissions, MFA enrollment rate
- Automation inventory: active Flows, Process Builders, Workflow Rules, Apex triggers — with last-modified date and owner

## Steps
1. Phase 1: `connect`
2. Phase 2: `audit-governor-limits`
3. Phase 3: `audit-api-usage`
4. Phase 4: `audit-storage`
5. Phase 5: `audit-security`
6. Phase 6: `audit-automations`
7. Phase 7: `produce-summary`
8. Phase 8: `submit`
