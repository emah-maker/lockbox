# FRAIM Job: sf-user-and-access-management

## Intent
Execute user and access changes in Salesforce — provisioning users, assigning profiles and permission sets, managing roles, and configuring sharing rules — with a verification step to confirm the intended access was applied.

## Outcome
- **Reviewable deliverable:** A .docx document at docs/salesforce/sf-user-and-access-management-{YYYY-MM-DD}.docx with request summary, changes applied (before/after values), verification results per change, and any failure remediation steps
- User records created, updated, or deactivated per the request
- Profile, permission set, and role assignments applied
- Sharing rules created or modified if the request requires record-level access
- Access verified: the affected user can (or cannot) access the intended records

## Steps

2. Phase 2: `validate-request`
3. Phase 3: `execute-changes`
4. Phase 4: `verify-access`
5. Phase 5: `produce-summary`
6. Phase 6: `submit`
