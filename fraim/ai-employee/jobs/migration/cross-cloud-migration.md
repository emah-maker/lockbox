# FRAIM Job: cross-cloud-migration

## Intent
Move cloud infrastructure between providers (AWS → GCP, GCP → Azure, AWS → Azure, or any combination) with full resource inventory, per-resource strategy selection, IaC translation, network cutover planning, and validated rollback before a production switch.

## Outcome
- **Migration summary**: `docs/migration/{issue_number}-migration-summary.md` — final record of migration scope, strategy decisions, IaC locations, and the DNS cutover runbook
- **Target infrastructure**: Fully provisioned in the target cloud and validated, running in parallel. Source infrastructure remains live until the user executes the DNS cutover runbook to flip the final bit.

## Steps
1. Phase 1: `cloud-migration-scoping`
2. Phase 2: `resource-inventory`
3. Phase 3: `migration-strategy-selection`
4. Phase 4: `iac-translation`
5. Phase 5: `network-and-dns-planning`
6. Phase 6: `dry-run-validation`
7. Phase 7: `rollback-planning`
8. Phase 8: `execute-migration`
9. Phase 9: `post-migration-validation`
10. Phase 10: `cutover-readiness`
11. Phase 11: `execute-cutover`
12. Phase 12: `submit`
13. Phase 13: `address-feedback`
14. Phase 14: `retrospective`
