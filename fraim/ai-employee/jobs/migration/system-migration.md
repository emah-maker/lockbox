# FRAIM Job: system-migration

## Intent
Migrate an existing system from one stack or boundary to another with explicit baseline capture, one-unit-at-a-time execution, domain-aware parity review, and cutover readiness discipline.

## Outcome
- Final artifact: `docs/evidence/{issue_number}-migration-work-list.md`
- Supporting evidence: `docs/evidence/{issue_number}-migration-evidence.md`
- Review evidence: `docs/evidence/{issue_number}-migration-review.md`
- Each migration unit is either completed against an explicit parity contract or left with a documented blocker, deferral, or rollback note

## Steps
1. Phase 1: `migration-scoping`
2. Phase 2: `migration-unit-discovery`
3. Phase 3: `baseline-capture`
4. Phase 4: `parity-contract-authoring`
5. Phase 5: `migration-scope-slicing`
6. Phase 6: `migrate-next-unit`
7. Phase 7: `parity-review`
8. Phase 8: `coverage-cross-analysis`
9. Phase 9: `fix-gaps`
10. Phase 10: `advance-or-loop`
11. Phase 11: `cutover-readiness`
12. Phase 12: `submit`
13. Phase 13: `address-feedback`
14. Phase 14: `retrospective`
