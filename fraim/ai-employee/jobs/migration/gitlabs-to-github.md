# FRAIM Job: gitlabs-to-github

## Intent
Migrate one or more repositories from GitLab to GitHub with controlled risk, explicit user approvals, and validation at every phase.

## Outcome
- Repositories, branches, tags, and history are migrated.
- Issues/work items, release artifacts, and metadata are migrated or intentionally mapped.
- CI/CD, secrets, environments, webhooks, and automations are migrated and validated.
- Team access model, branch protection, and governance requirements.
- Cutover is executed with rollback protection and post-cutover validation.

## Steps
1. Phase 1: `intake-and-discovery`
2. Phase 2: `scope-and-success-criteria`
3. Phase 3: `access-and-change-freeze`
4. Phase 4: `backup-and-export-baseline`
5. Phase 5: `create-github-target-foundation`
6. Phase 6: `migrate-git-history-and-branches`
7. Phase 7: `migrate-issues-mrs-and-releases`
8. Phase 8: `port-ci-cd-and-environments`
9. Phase 9: `migrate-integrations-and-automation`
10. Phase 10: `dry-run-validation`
11. Phase 11: `cutover-readiness-review`
12. Phase 12: `execute-cutover`
13. Phase 13: `post-cutover-validation`
14. Phase 14: `hypercare-and-decommission`
15. Phase 15: `submit`
