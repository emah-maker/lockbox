# FRAIM Job: contribute-to-fraim

## Intent
Allow users to contribute their custom Jobs, Skills, Rules, and Values back to the core FRAIM project. This job asks the user which specific capabilities they want to share, packages them, and files a contribution issue in the FRAIM repository.

## Outcome
- Final artifact: A detailed contribution issue filed in the FRAIM repository with packaged artifacts.
- **Improved Ecosystem**: The user's proven capabilities are shared with the broader FRAIM community.

## Steps
1. Phase 1: `gather-contribution-intent`
2. Phase 2: `discover-contribution-artifacts`
3. Phase 3: `confirm-contribution-package`
4. Phase 4: `file-contribution-issue`
5. Phase 5: `completion`
