# FRAIM Job: support-case-resolution

## Intent
Resolve support tickets end to end from the support system of record: claim or receive a ticket, choose the approved SOP playbook, invoke the correct fulfillment path, and write the final auditable result back to the support ticket.

## Outcome
- **Reviewable deliverable**: The support ticket updated in the configured support system with work notes, final state, FRAIM correlation id, selected playbook/action, validation result, fulfillment result, communication status, and backend audit references
- Ticket intake normalized from the configured support system
- Fulfillment action executed or clearly blocked with reason
- Support record updated with status, work note, final disposition, and FRAIM correlation id
- User communication dispatched or staged through the configured admin delivery path
- Canonical evidence summarized in the support ticket and correlated to backend audit references
- Phase-level capabilities available for support-system reads, decision prompt packaging, fulfillment actions, and support-system writeback

## Steps
1. Phase 1: `connect-support-system`
2. Phase 2: `load-ticket`
3. Phase 3: `classify-request`
4. Phase 4: `validate-and-decide`
5. Phase 5: `execute-fulfillment`
6. Phase 6: `notify-user`
7. Phase 7: `write-support-update`
8. Phase 8: `submit`
