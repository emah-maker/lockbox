# FRAIM Job: loyalty-program-management

## Intent
Create and manage loyalty programs — designing program rules, enrolling member cohorts, and tracking balances — to drive retention and reward high-value customer behavior.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/customer-success/loyalty-program-{YYYY-MM-DD}.docx with sections: Program Details (name, goal, currency, earning rule, redemption type), Enrollment Results (cohort, member count, balance samples), and Loyalty Overview
- New loyalty program created in the CRM (if requested), or existing program reviewed
- Target member cohort enrolled with confirmed enrollment count and initial balances
- Program summary with enrollment stats, tier distribution, and redemption options

## Steps
1. Phase 1: `connect`
2. Phase 2: `review-programs`
3. Phase 3: `design-program`
4. Phase 4: `create-program`
5. Phase 5: `enroll-members`
6. Phase 6: `produce-summary`
7. Phase 7: `submit`
