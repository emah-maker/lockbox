# FRAIM Job: support-system-operationalization

## Intent
Operationalize the support system once so that support requests can thereafter be resolved deterministically and securely. Connect the support ticket system and every other system support must act on, each through a least-privilege access script provided by the team that owns it, and wire them into the support configuration so downstream support jobs run without further setup.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/support/operationalization/support-operationalization-{YYYY-MM-DD}.docx with sections: Configured Systems, Verification Results, Unconfigured Gaps, Unblocked Jobs, and Remaining Steps
- `fraim/config.json` wired with one name-to-script pair per system (the ticket system, plus each downstream system support acts on)
- Every configured access script verified against its least-privilege self-test before downstream support jobs rely on it

## Steps
1. Phase 1: `discover-systems`
2. Phase 2: `explain-access-script-contract`
3. Phase 3: `author-access-scripts`
4. Phase 4: `wire-config`
5. Phase 5: `verify-access-scripts`
6. Phase 6: `produce-operationalization-report`
7. Phase 7: `submit`
