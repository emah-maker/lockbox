# FRAIM Job: generate-audit-evidence

## Intent
Generate comprehensive compliance audit documentation by analyzing system implementations against specific regulatory requirements and evidence.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at `docs/compliance/generate-audit-evidence-{YYYY-MM-DD}.pptx` generated from the final artifact; this is the outcome delivered for stakeholder review, with the .md below as the canonical agent-side record.
- Final artifact: The audit report at `docs/compliance/generate-audit-evidence-{YYYY-MM-DD}.md` with evidence matrix, regulation-by-regulation compliance status, remediation roadmap, and technical proof table.
- **Evidence Matrix**: A technical proof table mapping implementation evidence to regulatory clauses.
- **Remediation Issues**: GitHub issues automatically filed for any detected compliance gaps.
- Individual audit reports organized by regulation (e.g., GDPR, SOC2).
