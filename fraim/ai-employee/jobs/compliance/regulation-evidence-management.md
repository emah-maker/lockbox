# FRAIM Job: regulation-evidence-management

## Intent
Generate an auditor-ready evidence package for a single regulation — SOC 2, ISO 27001, GDPR, CCPA/CPRA, HIPAA, PCI-DSS, or another configured regulation — by scoping applicable clauses, collecting evidence against each, validating completeness, and filing gaps as remediation issues. One job, parameterized by regulation; the agent picks the correct planning and evidence-collection skills per run.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/compliance/compliance-review-{YYYY-MM-DD}/regulation-{regulation}-evidence-{YYYY-MM-DD}.pptx with scope statement, evidence matrix dashboard, control-to-artifact mapping, and gap analysis summary.
- **Scope statement**: Clause-level applicability for the regulation under review.
- **Evidence matrix**: Clause/control → evidence artifact citations.
- **Gap remediation issues**: Filed via `gap-analysis-aggregation` for missing / stale items.

## Steps
1. Phase 1: `evidence-planning-and-scoping`
2. Phase 2: `automated-evidence-collection`
3. Phase 3: `evidence-documentation-and-formatting`
4. Phase 4: `evidence-validation-and-gap-analysis`
5. Phase 5: `regulation-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
