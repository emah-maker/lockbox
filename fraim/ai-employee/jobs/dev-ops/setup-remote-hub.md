# FRAIM Job: setup-remote-hub

## Intent
Provision a remote machine, install the FRAIM Hub runtime, and register it as a reachable host in the local Hub.

## Outcome
- A cloud VM (Azure by default) running the FRAIM Hub server on port 3000.
- The remote Hub is accessible with an auth token protecting its `/api/ai-hub/*` routes.
- The local Hub shows the new host as `online` in `GET /api/ai-hub/hosts/:id/health`.

## Steps
1. Phase 1: `authenticate`
2. Phase 2: `provision`
3. Phase 3: `install`
4. Phase 4: `configure`
5. Phase 5: `start`
6. Phase 6: `register`
