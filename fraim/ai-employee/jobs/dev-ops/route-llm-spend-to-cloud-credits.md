# FRAIM Job: route-llm-spend-to-cloud-credits

## Intent
Stop paying for LLM usage out of cash burn. Take whatever LLM-using agent or codebase the user has today (Claude Code, Codex, Gemini CLI, an Anthropic SDK app, etc.) and redirect its traffic to a cloud where the user has free credits, so the credits absorb the spend instead of the company card. Per-shell flip - production traffic continues uninterrupted on the original provider until the user opts in.

## Outcome
- Final artifact: `docs/llm-routing/<cloud>-<provider>-{DATE}.md` capturing the chosen routing pair and the flip protocol.
- **Working flip script** at `$HOME/.cloud-llm-flip/use-<cloud>-<provider>.<sh|ps1>` the user can dot-source per shell.
- **Verified live invoke** through the chosen cloud provider - no synthetic test passes.
- **Zero secrets in repo** - bearer tokens / service accounts / API keys live outside the user's working trees.

## Steps
1. Phase 1: `detect-llm-spend`
2. Phase 2: `select-cloud-target`
3. Phase 3: `configure-cloud-provider`
4. Phase 4: `configure-agent-routing`
5. Phase 5: `verify-live-invoke`
6. Phase 6: `document-routing-protocol`
7. Phase 7: `retrospective`
