# FRAIM Job: slo-design-and-implementation

## Intent
Design user-journey-aligned SLIs and SLOs, calculate error budgets, implement burn-rate alerting, and replace noisy threshold alerts with meaningful on-call pages that carry triage context.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/dev-ops/slo-design-{YYYY-MM-DD}.pptx containing SLI/SLO definitions, error budget calculations, burn-rate alert specifications, and dashboard configuration with SLO status visualization.
- **SLI/SLO Definitions**: At least 3 SLOs covering availability, latency, and correctness for key user journeys.
- **Error Budgets**: 28-day rolling error budgets with explicit policy for how budget is spent.
- **Burn-Rate Alerts**: Two-window alerting (1h fast-burn + 6h slow-burn) for each SLO.
- **Dashboard Config**: Grafana or equivalent dashboard spec with SLO status, budget remaining, and burn rate.

## Steps
1. Phase 1: `slo-definition`
2. Phase 2: `error-budget-calc`
3. Phase 3: `burn-rate-alerting`
4. Phase 4: `dashboard-setup`
5. Phase 5: `slo-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
