# FRAIM Job: cloud-cost-optimization

## Intent
Reduce cloud spend on a running production environment without breaking it. Systematically analyze costs, identify the biggest savings opportunities, weigh each against its production-impact risk, and implement the safe ones with rollback plans in hand. Single job parameterized by deployment platform — composes the platform-specific skill set (Azure / AWS / GCP) based on a Phase 1 platform decision.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/dev-ops/cloud-cost-optimization-{YYYY-MM-DD}.docx with implemented changes, cost savings summary, prioritized optimization actions with risk assessments, and rollback plans.
- **Cost Reduction**: Verified reduction in cloud consumption.
- **Actionable Plan**: Prioritized list of optimization actions with risk assessment and rollback plans.

## Steps
1. Phase 1: `platform-selection`
2. Phase 2: `verify-authentication`
3. Phase 3: `gather-cost-data`
4. Phase 4: `identify-opportunities`
5. Phase 5: `prioritize-actions`
6. Phase 6: `execute-changes`
7. Phase 7: `cost-optimization-submission`
8. Phase 8: `address-feedback`
9. Phase 9: `retrospective`
