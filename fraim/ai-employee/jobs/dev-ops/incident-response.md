# FRAIM Job: incident-response

## Intent
Run structured incident command from first alert to blameless postmortem — cutting MTTR by eliminating coordination overhead and ensuring every incident produces action items, not just a resolved ticket.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/dev-ops/incident-postmortem-{YYYY-MM-DD}.docx containing incident timeline, SEV classification, root cause analysis, contributing factors, and action items with owners.
- Live incident channel: structured coordination with role assignments, timeboxed investigation rounds, and status page updates.
- **SEV Classification**: Severity determined in < 2 minutes using the 4-tier matrix.
- **Role Assignment**: IC, Comms Lead, Tech Lead, and Scribe assigned at incident open.
- **Postmortem**: Timeline, root cause, contributing factors, and action items with owners.

## Steps
1. Phase 1: `severity-classification`
2. Phase 2: `role-assignment`
3. Phase 3: `investigation-timeboxing`
4. Phase 4: `resolution`
5. Phase 5: `postmortem`
6. Phase 6: `incident-submission`
7. Phase 7: `address-feedback`
8. Phase 8: `retrospective`
