# FRAIM Job: cloud-performance-diagnosis

## Intent
Diagnose performance constraints (CPU, Memory, Network, Latency) within a cloud-hosted environment. Single job parameterized by deployment platform — composes the platform-specific telemetry / trace / log skills (Azure / AWS / GCP) based on a Phase 1 platform decision. Non-invasive data collection, bottleneck analysis, prioritized recommendations.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/dev-ops/cloud-performance-diagnosis-{YYYY-MM-DD}.docx with metric-backed diagnosis, identified bottlenecks, and prioritized cloud performance optimization recommendations.
- **Metric-Backed Diagnosis**: Hypothesis based on real-time telemetry, traces, and logs.
- **Resource Efficiency**: Identification of over-provisioned or under-performing cloud resources.

## Steps
1. Phase 1: `platform-selection`
2. Phase 2: `setup-diagnostic-session`
3. Phase 3: `collect-performance-data`
4. Phase 4: `analyze-bottlenecks`
5. Phase 5: `formulate-optimization-plan`
6. Phase 6: `performance-submission`
7. Phase 7: `address-feedback`
8. Phase 8: `retrospective`
