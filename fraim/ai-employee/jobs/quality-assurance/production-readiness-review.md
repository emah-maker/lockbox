# FRAIM Job: production-readiness-review

## Intent
Perform a standalone production-readiness review for a real production workload. This job evaluates whether a system can be operated safely and repeatedly in production by reviewing security posture, high availability, backup and restore, observability, release safety, and operational runbooks against the declared scope.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/quality-assurance/production-readiness-{YYYY-MM-DD}.pptx with six-dimension scorecard (security posture, availability/resilience, backup/restore, observability/ops, release safety, governance), launch decision gate (pass/flag/fail), and remediation queue with priority scoring.
- A durable production-readiness review with launch blockers, validation evidence, control-by-control status, remediation queue, and an explicit go / flag / fail decision
- A rich quality score emitted to `fraim_quality_scores` so the analytics Quality tab shows a dedicated Production Readiness tile with sub-dimension breakdown

## Steps
1. Phase 1: `readiness-scope-and-context`
2. Phase 2: `evidence-collection`
3. Phase 3: `control-validation`
4. Phase 4: `readiness-report`
5. Phase 5: `address-feedback`
6. Phase 6: `retrospective`
