# FRAIM Job: performance-benchmarking

## Intent
Establish performance baselines, run load testing at realistic traffic levels, analyze Core Web Vitals, and produce a threshold-based performance report with actionable optimization recommendations.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/quality-assurance/performance-benchmarking-{YYYY-MM-DD}.pptx with baseline metrics (P50/P95/P99 latencies), load test results dashboard, Core Web Vitals assessment, and optimization recommendations with impact scoring.
- **Baseline Metrics**: Current performance at normal load — P50, P95, P99 latency and error rate per endpoint.
- **Load Test Results**: Performance under target peak load with failure thresholds identified.
- **Core Web Vitals Assessment**: LCP, INP, CLS scores for key user-facing pages.
- **Optimization Recommendations**: Prioritized performance improvements with expected impact.

## Steps
1. Phase 1: `baseline-measurement`
2. Phase 2: `load-testing`
3. Phase 3: `cwv-analysis`
4. Phase 4: `threshold-reporting`
5. Phase 5: `performance-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
