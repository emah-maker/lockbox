# FRAIM Job: iterative-quality-improvement

## Intent
To systematically improve application quality through iterative cycles of Review → Critique → Fix → Validate, ensuring high-quality, production-ready applications.

Use this job for comprehensive quality improvement when applications need multiple rounds of review and fixes before meeting production standards, typically before major releases or after significant feature implementations.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/quality-assurance/iterative-improvement-{YYYY-MM-DD}.pptx containing iteration cycle summaries, resolved issues dashboard, quality metrics tracking across cycles, and production readiness scorecard.
- **Resolved Issues**: All identified issues are fixed and validated.
- **Production Readiness**: Application is stable, performs well, and provides a good user experience.

## Steps
1. Phase 1: `initial-review`
2. Phase 2: `critique-and-issue-identification`
3. Phase 3: `systematic-fixes`
4. Phase 4: `validation`
5. Phase 5: `iteration-decision`
6. Phase 6: `documentation-and-handoff`
7. Phase 7: `quality-submission`
8. Phase 8: `address-feedback`
9. Phase 9: `retrospective`
