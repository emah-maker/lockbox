# FRAIM Job: code-quality-assessment

## Intent
To perform a deep analysis of the codebase's quality, evaluating it against FRAIM's standards and generating a comprehensive health report with actionable recommendations. Use it when the question is "How healthy is this codebase's implementation?"

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/quality-assurance/code-quality-report-{YYYY-MM-DD}.pptx with overall grade, multi-dimension review scorecards (code quality, broken windows, type safety, error handling, architecture, maintainability), and actionable remediation recommendations.
- **Graded Quality**: An overall grade (A-F) for the codebase.
- **Multi-Dimension Review**: Explicit findings for code quality and broken windows.
- **Actionable Remediation**: Prioritized recommendations for improving codebase quality.

## Steps
1. Phase 1: `environment-check`
2. Phase 2: `evaluate-codebase-quality`
3. Phase 3: `author-quality-report`
4. Phase 4: `review-findings`
5. Phase 5: `quality-score-emission`
6. Phase 6: `code-quality-submission`
