# FRAIM Job: accessibility-audit

## Intent
Audit a web application against WCAG 2.1 AA criteria using automated scanning and manual testing, produce a severity-scored findings report, and deliver a prioritized remediation plan.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/quality-assurance/accessibility-audit-{YYYY-MM-DD}.docx with WCAG 2.1 AA Compliance Score, Severity-Scored Findings, and Remediation Plan sections.
- **WCAG 2.1 AA Compliance Score**: Pass/fail/partial for each applicable success criterion.
- **Severity-Scored Findings**: Each finding scored by severity (critical, serious, moderate, minor).
- **Remediation Plan**: Prioritized fix list with implementation effort and WCAG criterion reference.

## Steps
1. Phase 1: `automated-scan`
2. Phase 2: `manual-testing`
3. Phase 3: `wcag-scoring`
4. Phase 4: `remediation-plan`
5. Phase 5: `accessibility-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
