# FRAIM Job: career-networking

## Intent
Build and operate a systematic networking strategy: who to contact, when to contact them, how to personalize outreach, and how to turn warm-path intelligence into real application leverage.

## Outcome
- A `Networking Plan` DOCX at `docs/career/{slug}-career-networking-{YYYY-MM-DD}.docx`
- Canonical markdown source at `docs/career/{slug}-career-networking-{YYYY-MM-DD}.md`, generated before the DOCX export
- >=3 connection tiers per target company: Tier 1 (hiring managers), Tier 2 (employees), Tier 3 (thought leaders)
- Warm connection path research for Tier 1 and Tier 2 contacts
- Personalized outreach message templates per tier (<=5 sentences, specific to recipient background)
- Networking calendar covering >=3 weeks with outreach and follow-up timing
- Status tracker for each target contact
- Role-linked recommendations about whether to network before applying, after applying, or instead of applying
- All LinkedIn write actions (connection requests, messages) performed browser-based via existing skills, as a post-approval action after the manager approves the plan

## Steps
1. Phase 1: `gather-networking-context`
2. Phase 2: `map-target-strategy`
3. Phase 3: `identify-and-score-contacts`
4. Phase 4: `draft-outreach-messages`
5. Phase 5: `plan-public-engagement`
6. Phase 6: `assemble-networking-plan`
7. Phase 7: `submit`
8. Phase 8: `address-feedback`
9. Phase 9: `retrospective`
