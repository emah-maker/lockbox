# FRAIM Job: resume-creation

## Intent
Build or optimize a resume from the user's qualifications, career strategy, LinkedIn profile, and GitHub, applying evidence-backed resume principles that maximize ATS clearance and human impact in the first 10 seconds.

## Outcome
- A `Resume Rewrite` artifact at `docs/career/resume-{slug}-{YYYY-MM-DD}.docx` for ATS-safe Word output, `docs/career/resume-{slug}-{YYYY-MM-DD}.html` for HTML/PDF output, or structured Canva-ready content blocks if that format is selected. The artifact includes impact-first bullet format, ATS-safe layout when applicable, consolidated Additional Experience section, and a role-targeted variant with relevant keywords if a job description is provided
- Canonical source at `docs/career/resume-{slug}-{YYYY-MM-DD}.md` for Word/PDF paths, generated before the DOCX/HTML export or Canva-ready content blocks
- **Reviewer-facing evidence:** Record the source-to-resume edit map summary, heading sanity result, ATS formatting result, and DOCX semantic formatting result before submission.
- Every bullet rewritten to impact-first format ("Outcome X through action Y")
- ATS-safe output: no columns, tables, or text boxes
- Older roles consolidated into a polished dateless `Additional Experience` section
- If a job description is provided: a role-targeted variant with relevant keywords surfaced

## Steps
1. Phase 1: `gather-career-history`
2. Phase 2: `build-resume`
3. Phase 3: `submit`
4. Phase 4: `address-feedback`
5. Phase 5: `retrospective`
