# FRAIM Job: career-spec

## Intent
Build a plain-language Career Strategy that helps the user understand where they fit best, what proof they already have, what gaps to close, and which CAREEna job to run next.

## Outcome
- A `Career Strategy` DOCX at `docs/career/{slug}-career-spec-{YYYY-MM-DD}.docx` using `templates/career/CAREER-STRATEGY-TEMPLATE.md`, marked `PERSONAL - CAREER CONFIDENTIAL`
- Canonical markdown source at `docs/career/{slug}-career-spec-{YYYY-MM-DD}.md`, generated before the DOCX export
- Customer analysis for hiring companies, family/dependents, and the user
- Value proposition assessment in plain language, backed by evidence from the user's history
- Target segment recommendation: company stage, size, industry, and role type
- Gap analysis and next actions framed as specific steps to close, not permanent deficits
- Recommended CAREEna path that names the next 1-3 jobs to run based on the user's situation

## Steps
1. Phase 1: `gather-career-context`
2. Phase 2: `analyze-customers`
3. Phase 3: `synthesize-positioning`
4. Phase 4: `submit`
5. Phase 5: `address-feedback`
6. Phase 6: `retrospective`
