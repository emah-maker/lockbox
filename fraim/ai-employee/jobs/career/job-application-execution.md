# FRAIM Job: job-application-execution

## Intent
Run the user's application loop end to end: source relevant openings, prioritize the ones worth real effort, tailor the application package, track each submission, and keep the user moving through the pipeline with less drift and fewer missed follow-ups.

## Outcome
- A `Job Application Tracker` DOCX at `docs/career/{slug}-job-application-execution-{YYYY-MM-DD}.docx`
- Canonical markdown source at `docs/career/{slug}-job-application-execution-{YYYY-MM-DD}.md`, generated before the DOCX export
- A sourced and prioritized target-role list with explicit reasons to apply or skip
- Tailored application packages per role (resume emphasis, profile tweaks, and cover-note inputs when needed)
- Submission tracker with status, deadlines, links, and next actions
- Follow-up plan for recruiter nudges, referral asks, and post-apply check-ins

## Steps
1. Phase 1: `application-strategy`
2. Phase 2: `application-packaging`
3. Phase 3: `application-submission-ops`
4. Phase 4: `submit`
5. Phase 5: `address-feedback`
6. Phase 6: `retrospective`
