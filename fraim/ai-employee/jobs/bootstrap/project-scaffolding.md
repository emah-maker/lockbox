# FRAIM Job: project-scaffolding

## Intent
Scaffold a new FRAIM project from 0 to 80% production-ready, setting up test infrastructure, port management, issue filing, MCP connectivity, source organization, and e2e tests. The agent reads reference templates, analyzes the project context, and generates code adapted to the specific project's language, framework, and conventions.

## Outcome
- A working project scaffold with all core components:
  - `src/core/utils/git-utils.{ext}` with port management and branch-based database naming
  - `{project-root}/test-utils.{ext} (in the project's test directory)` with BaseTestCase, tag filtering, and runTests
  - `src/issues.{ext}` with issue filing endpoint for the project's configured issue tracker
  - `src/mcp-server.{ext}` with MCP server entry point (/health, /mcp)
  - `{project-root}/shared-server-utils.{ext} (in the project's test directory)` with e2e helpers (startTestServer, sendMCPRequest, waitForServer)
  - `e2e/` directory with a sample end-to-end test
- Generated code adapted to the project's detected language and framework
- Next-step guidance for deployment or feature building

## Steps
1. Phase 1: `project-analysis`
2. Phase 2: `core-infrastructure`
3. Phase 3: `test-infrastructure`
4. Phase 4: `server-and-integration`
5. Phase 5: `validation-and-next-steps`
