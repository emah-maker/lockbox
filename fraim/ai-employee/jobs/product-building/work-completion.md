# FRAIM Job: work-completion

## Intent
Systematically merge any completed work (feature, bug fix, or chore) into the main codebase. This job handles the critical "last mile": merging, verifying integrity on the main branch, and cleaning up artifacts to prevent work loss or repository pollution.

## Outcome
- **Merged Code**: The feature branch is successfully merged into `master/main`.
- **Verified Main**: The main branch CI passes *after* the merge.
- **Closed Issue**: The issue tracker reflects the completed status.
- **Clean Workspace**: Local and remote feature branches are deleted and the issue worktree is removed when applicable.

## Steps
1. Phase 1: `resolution-merge`
2. Phase 2: `resolution-verification`
3. Phase 3: `resolution-cleanup`
