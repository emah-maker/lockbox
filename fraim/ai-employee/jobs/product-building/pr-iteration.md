# FRAIM Job: pr-iteration

## Intent
Autonomously handle the Pull Request lifecycle, including monitoring CI status, processing reviewer feedback, and verifying fixes. This job aims to reduce human intervention during the code review cycle.

## Outcome
- **Green CI**: All GitHub Actions/CI checks pass.
- **Resolved Comments**: All reviewer feedback is addressed and marked as resolved.
- **Updated PR**: The PR is updated with fixes and ready for re-review.

## Steps
1. Phase 1: `pr-monitoring`
2. Phase 2: `pr-feedback-processing`
3. Phase 3: `pr-verification`
4. Phase 4: `pr-submission`
