# FRAIM Job: user-facing-prototyping

## Intent
Quickly explore and demonstrate user-facing concepts, prioritizing UX and visual flow over technical perfection. This is a stakeholder-facing artifact meant to validate look, feel, and user utility.

## Outcome
- **Reviewable deliverable**: A set of interactive HTML/CSS prototype files at `docs/prototypes/{slug}/` that a stakeholder can open in a browser and walk through. The prototype IS the deliverable — not a screenshot or a deck of it.
- Documented UX findings on flow, usability, and design effectiveness in `docs/prototypes/{slug}/README.md`

## Steps
1. Phase 1: `prototype-scoping`
2. Phase 2: `prototype-execution`
3. Phase 3: `prototype-demo`
4. Phase 4: `prototype-decision`
5. Phase 5: `prototype-submission`
6. Phase 6: `address-feedback`
7. Phase 7: `retrospective`
