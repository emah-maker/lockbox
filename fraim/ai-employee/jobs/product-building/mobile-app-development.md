# FRAIM Job: mobile-app-development

## Intent
Create production-ready mobile applications from concept to store submission, following platform best practices (Apple HIG / Material 3) and store policies (App Store Review Guidelines / Play Store Policies). Single job parameterized by `platform` (`ios`, `android`, or `both` for cross-platform builds) — composes the platform-specific skill set based on a Phase 1 decision.

## Outcome
- **Production Mobile App**: Fully functional iOS .ipa and/or Android .aab ready for store submission.
- **Complete Documentation**: Technical, API, and user docs.
- **Compliance Validation**: Privacy manifest / Data Safety form; AI disclosure; export compliance; accessibility.
- **Monitoring Setup**: Crash reporting, performance monitoring, analytics.
- **Artifact Handoff**: Binary path(s), mapping/symbol files, version metadata — symmetric across platforms so the submission job consumes a uniform contract.

## Steps
1. Phase 1: `platform-selection`
2. Phase 2: `project-setup`
3. Phase 3: `architecture-design`
4. Phase 4: `core-implementation`
5. Phase 5: `integration-setup`
6. Phase 6: `performance-optimization`
7. Phase 7: `compliance-validation`
8. Phase 8: `observability-setup`
9. Phase 9: `store-preparation`
10. Phase 10: `deployment-review`
11. Phase 11: `deployment`
12. Phase 12: `monitoring-setup`
