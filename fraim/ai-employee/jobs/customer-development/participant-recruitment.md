# FRAIM Job: participant-recruitment

## Intent
Convert known prospects into scheduled customer discovery interviews using the "Humble Inquiry" approach. This job takes an explicit list of qualified prospects (from `customer-prospect-discovery`, a user-provided CSV, CRM export, or named people/accounts) and executes personalized outreach to recruit them for 15-minute customer discovery conversations.

## Outcome
- **Primary artifacts**: A dated run bundle update in `docs/customer-development/customer-prospect-discovery/` containing:
  - the existing dossier file for the run, or a new `participant-recruitment-{YYYY-MM-DD}.md` if recruitment starts standalone
  - `prospects-{YYYY-MM-DD}.csv` with outreach status and response-rate fields updated in place
- **Reviewable deliverable**: a .docx review copy generated from the run dossier via the author-docx skill at submission; the dossier .md remains the canonical record.
- **No net-new discovery outputs**: This job must not create `qualified-prospects-*`, `social-prospects-*`, `events-*`, `target-accounts-*`, or any other ad hoc prospect/event CSV. If the needed recruit list does not exist, stop and ask for the source or route to `customer-prospect-discovery`.
- **Personalized Inquiries**: Custom connection requests (under 300 characters) that ask for specific advice on a problem, never mentioning your solution.
- **Interview Pipeline**: 3-5 scheduled customer discovery interviews from successful recruitment.
- **Recruitment Metrics**: Response rates and conversion data for optimizing future outreach.

**Success criteria**: 30-50% response rate to connection requests, 10-20% conversion to scheduled interviews.

## Steps
1. Phase 1: `research-environment-setup`
2. Phase 2: `participant-identification-and-qualification`
3. Phase 3: `outreach-strategy-and-copy-engineering`
4. Phase 4: `submit`
5. Phase 5: `address-feedback`
6. Phase 6: `retrospective`
