# FRAIM Job: process-interview-notes

## Intent
Extract, structure, and analyze customer insights from raw interview notes, transcript, or recording from a **single** customer interview. Produce one consolidated artifact containing the analysis, the personalized follow-up email, and a local quality summary in YAML frontmatter that the founder (and the holistic `review-customer-development` job) read to coach interview *technique*. Portfolio-level customer-development scoring is owned by `review-customer-development`.

## Outcome
- **Reviewable deliverable**: a .docx review copy generated from the interview artifact via the author-docx skill at submission; this is the outcome delivered for review, with the .md below as the canonical agent-side record.
- **Single artifact**: `docs/customer-development/interviews/[customer-name-slug]-interview.md`. When `interview-preparation` ran for this participant, this is the same file it created; this job adds the analysis so one file per customer covers prep, interview, and follow-up. The file contains:
  1. **YAML frontmatter** at the very top with a `quality:` block (composite score, participant scores, evidence metrics, coaching note, interviewee, company, timestamp). The frontmatter is the human-readable summary of how this *one* interview went, consumed locally for technique coaching and read by `review-customer-development` as one input among many.
  2. **Bottom Line Up Front** section.
  3. **Participant Profile** with Fit / Urgency / Authority scores.
  4. **Cleaned Signals** (chronological, with quotes).
  5. **Extracted Insights** (tagged Pain Point / Feature Request / Workflow Gap / Praise).
  6. **Quality Assessment** (quote-by-quote table, bias risk, notable absences).
  7. **Validation** of any prep-doc hypotheses.
  8. **Open Questions / Follow-Ups**.
  9. **Follow-Up Email** as a `## Follow-Up Email Draft` section inside the same file. Do NOT write a separate follow-up file.
  10. **Source Notes** (the raw input as provided, for traceability).

## Steps
1. Phase 1: `raw-input-processing`
2. Phase 2: `single-session-insight-extraction`
3. Phase 3: `participant-scoring`
4. Phase 4: `conversation-quality-assessment`
5. Phase 5: `artifact-generation`
6. Phase 6: `artifact-submission`
7. Phase 7: `address-feedback`
8. Phase 8: `retrospective`
