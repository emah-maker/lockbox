# FRAIM Job: interview-preparation

## Intent
Systematically prepare for customer interviews by performing deep prospect research and designing questions that adhere to the Mom Test protocol, ensuring high-fidelity learnings and bias avoidance.

## Outcome
- **Reviewable deliverable**: a .docx review copy generated from the final artifact via the author-docx skill at submission; this is the outcome delivered for review, with the .md below as the canonical agent-side record.
- Final artifact: the customer's interview file at `docs/customer-development/interviews/[customer-name-slug]-interview.md`, created by this job with the preparation recorded under a `## Interview Prep` section. The same file later receives the interview analysis from `process-interview-notes`, so each customer has one file telling the whole story.
- **Prospect Biography**: A research dossier containing the prospect's role, company history, and recent platform activity.
- **Mom Test Question Set**: A custom script of 5-7 "Anchor Questions" that follow the bias-avoidance protocol.

## Steps
1. Phase 1: `research-environment-setup`
2. Phase 2: `prospect-information-collection`
3. Phase 3: `hypothesis-driven-interview-design`
4. Phase 4: `mom-test-question-engineering`
5. Phase 5: `prep-document-finalization`
6. Phase 6: `prep-submission`
7. Phase 7: `address-feedback`
8. Phase 8: `retrospective`
