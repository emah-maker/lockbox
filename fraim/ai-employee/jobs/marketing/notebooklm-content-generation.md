# FRAIM Job: notebooklm-content-generation

## Intent
Generate a NotebookLM artifact from approved source documents using one explicit output mode: `infographic`, `presentation`, `podcast`, `video-overview`, or `report`.

## Outcome
- **Reviewable deliverable**: A NotebookLM URL plus any exportable local artifact for the selected mode:
  - `infographic`: `docs/marketing/notebooklm-infographic-{YYYY-MM-DD}.pptx` when exported.
  - `presentation`: `docs/marketing/notebooklm-presentation-{YYYY-MM-DD}.pptx` when exported.
  - `podcast`: NotebookLM Audio Overview URL and download/export status.
  - `video-overview`: NotebookLM Video Overview URL and download/export status.
  - `report`: `docs/marketing/notebooklm-report-{YYYY-MM-DD}.md` and `.docx` when report text is available.
- A curated source set approved by the user before upload.
- Generation evidence that records the selected output mode, source count, notebook URL, and export limitations.

## Steps
1. Phase 1: `gather-documents`
2. Phase 2: `select-output-mode`
3. Phase 3: `review-and-curate`
4. Phase 4: `authenticate-and-create`
5. Phase 5: `artifact-review`
6. Phase 6: `generate-artifact`
7. Phase 7: `submit`
8. Phase 8: `address-feedback`
9. Phase 9: `retrospective`
