# FRAIM Job: security-findings-command-center

## Intent
Run the command center for active security findings: consolidate inputs, separate real risk from noise, and maintain a remediation queue that engineering leadership can actually execute against.

## Outcome
- **Reviewable deliverable**: A .pptx presentation at docs/security/security-findings-command-center-{YYYY-MM-DD}.pptx containing unified findings ledger, prioritized remediation queue with severity and ownership, disposition trail, and executive summary dashboard of exposure metrics
- Unified findings ledger spanning scans, reviews, incidents, and manual reports
- Prioritized remediation queue with severity, exploitability, owner, and due date
- Disposition trail for accepted risk, false positives, and deferred work
- Executive summary of current exposure and the blockers to closure

## Steps
1. Phase 1: `findings-intake`
2. Phase 2: `findings-prioritization`
3. Phase 3: `findings-resolution-plan`
4. Phase 4: `submit`
5. Phase 5: `address-feedback`
6. Phase 6: `retrospective`
