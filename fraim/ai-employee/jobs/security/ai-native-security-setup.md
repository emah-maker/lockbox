# FRAIM Job: ai-native-security-setup

## Intent
Stand up the minimum viable security operating baseline for AI-native products and teams: identity, secrets, environment separation, review gates, and evidence hooks that let the team move fast without pretending security will be figured out later.

## Outcome
- **Reviewable deliverable**: A .docx document at docs/security/ai-native-security-setup-{YYYY-MM-DD}.docx with security baseline documentation (auth, secrets, environments, logging, review controls), prioritized implementation plan with owners and sequences, evidence mapping, and critical gaps analysis
- Security baseline covering auth, secrets, environments, logging, and review controls
- Prioritized implementation plan with owner, sequence, and validation expectations
- Initial evidence map showing how the team will prove controls later
- Clear list of critical gaps that block launch or external trust claims
