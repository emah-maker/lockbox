# Hardware

| File | What it is |
|---|---|
| `cad/main-case.sldprt` / `cad/main-case.step` | Main enclosure body (SolidWorks source + STEP export) |
| `cad/lid.sldprt` / `cad/lid.step` | Lid (SolidWorks source + STEP export) |
| `wiring-diagram.svg` | Functional wiring / block diagram of the electronics |

The enclosure went through two full revisions, designed for FDM printing, with
printed fit-test coupons for the hinge, port, screen bezel, power switch and
locking tab before each full assembly.

![Wiring diagram](wiring-diagram.svg)

The bill of materials and part-sourcing notes are in
[`docs/procurement/`](../docs/procurement/).
